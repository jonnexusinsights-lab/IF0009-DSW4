# El Problema del Manejo Descentralizado de Errores

* **Acoplamiento y Repetición de Código:**
  * Bloques `try-catch` dispersos en cada controlador REST.
  * Violación directa del *Principio de Responsabilidad Única (SRP)*.
* **Fuga de Información Sensible (OWASP Top 10):**
  * Traza de pila (*stack trace*) expuesta directamente al cliente en respuestas por defecto.
  * Revelación de nombres de tablas, clases internas y consultas SQL.
* **Inconsistencia de Respuestas:**
  * Respuestas HTTP sin estructura JSON homogénea entre diferentes controladores.

# Patrón de Manejo Centralizado con Spring Boot

* **Anotación Estereotipo `@RestControllerAdvice`:**
  * Intercepta excepciones de forma global mediante Programación Orientada a Aspectos (AOP).
  * Se aplica a todos los controladores anotados con `@RestController`.
* **Anotación `@ExceptionHandler`:**
  * Asocia un método Java con un tipo específico de excepción.
  * Construye la respuesta HTTP personalizada.
* **Estándar RFC 7807 (Problem Details):**
  * Estructura unificada para errores REST (`title`, `status`, `detail`, `instance`, `timestamp`).

# Ejemplo: Middleware Centralizado (`GlobalExceptionHandler`)

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<ErrorResponseDTO> handleNotFound(
            ResourceNotFoundException ex, HttpServletRequest request) {
        
        ErrorResponseDTO error = new ErrorResponseDTO(
            "Recurso No Encontrado", 404, ex.getMessage(), request.getRequestURI()
        );
        return new ResponseEntity<>(error, HttpStatus.NOT_FOUND);
    }
}
```

# Captura de Errores de Validación (`@Valid`)

```java
@ExceptionHandler(MethodArgumentNotValidException.class)
public ResponseEntity<ErrorResponseDTO> handleValidation(
        MethodArgumentNotValidException ex, HttpServletRequest request) {
    
    Map<String, String> errors = new HashMap<>();
    for (FieldError err : ex.getBindingResult().getFieldErrors()) {
        errors.put(err.getField(), err.getDefaultMessage());
    }

    ErrorResponseDTO response = new ErrorResponseDTO(
        "Error de Validación", 400, "Campos inválidos", 
        request.getRequestURI(), errors
    );
    return new ResponseEntity<>(response, HttpStatus.BAD_REQUEST);
}
```

# Buenas Prácticas y Trampas Comunes

* **NUNCA retorne código HTTP 200 OK con un JSON de error interno.**
* **Filtro Catch-All (`Exception.class`):**
  * Captura fallos inesperados y devuelve `500 Internal Server Error` sanitizado.
  * Registra el stacktrace completo en los logs del servidor mediante `Logger`.
* **Desacoplamiento:**
  * Defina excepciones de dominio personalizadas (`ResourceNotFoundException`, `BusinessRuleException`).
