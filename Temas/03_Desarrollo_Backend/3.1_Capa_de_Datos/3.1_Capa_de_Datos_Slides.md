# ¿Qué es la Persistencia y el Mapeo ORM?

* **Desajuste de Impedancia Objeto-Relacional:**
  * **Java:** Trabaja con objetos en memoria y referencias de grafo.
  * **Base de Datos:** Estructurada en tablas de dos dimensiones (filas y columnas) con llaves primarias/foráneas.
* **El Mapeo Objeto-Relacional (ORM):**
  * Patrón de diseño y herramienta de software que traduce automáticamente objetos a filas de bases de datos relacionales.
  * **JPA (Java Persistence API):** Especificación estándar de Java.
  * **Hibernate:** El motor (proveedor) de software que ejecuta JPA.

# Entidades Relacionales en JPA

* Una **Entidad** es un POJO de Java decorado con anotaciones JPA.
* **Anotaciones de Mapeo Esenciales:**
  * `@Entity`: Registra la clase como entidad persistente.
  * `@Table`: Asocia la entidad a una tabla física de la base de datos.
  * `@Id`: Define el campo que actuará como llave primaria (`PK`).
  * `@GeneratedValue`: Declara la estrategia de auto-incrementar.
  * `@Column`: Configura restricciones finas en columnas (nombres, nulos, longitudes).

# La Abstracción de Repositorios

* **DAO Tradicional:** Requería escribir extensas sentencias SQL manuales y procesar el ResultSet.
* **Spring Data JPA (`JpaRepository`):**
  * Interfaz de Java que extiende `JpaRepository<T, ID>`.
  * Genera automáticamente en tiempo de ejecución las implementaciones de operaciones CRUD estándar (`save`, `findById`, `deleteById`).
  * **Query Methods:** Generación de consultas automáticas según el nombre del método (ej. `findByActivo`).

# Mapeo de Procedimientos Almacenados

* En entornos corporativos, delegar lógica compleja al motor de la base de datos es habitual por rendimiento.
* **Soporte JPA para Stored Procedures:**
  * Decoración de la clase entidad con `@NamedStoredProcedureQuery`.
  * Definición de parámetros tipados mediante `@StoredProcedureParameter`.
  * Parámetros de entrada (`ParameterMode.IN`) y salida (`ParameterMode.OUT`).
  * Invocación simplificada con la anotación `@Procedure` en los repositorios.

# Paginación Física y Ordenamiento

* **Paginación en Memoria (Mala Práctica):** Cargar millones de filas a RAM para paginar con JS. Causa caídas de servidor y red.
* **Paginación Física (Buena Práctica):** Solicitar al motor de base de datos únicamente el fragmento requerido (`LIMIT` y `OFFSET`).
* **Soporte en Spring Data JPA:**
  * Interfaz `Pageable` para pasar número de página, tamaño y orden (`Sort`).
  * Clase `PageRequest.of` para instanciar la configuración de paginación.
  * Objeto de retorno `Page<T>` que encapsula el listado y metadatos totales.

# Analogías para Entender la Capa de Datos

* **El ORM como Traductor Simultáneo:**
  * Java habla inglés (objetos) y la base de datos habla español (tablas relacionales).
  * El ORM traduce conceptos (guardar objeto) a instrucciones nativas de base de datos (INSERT INTO) en tiempo real.

# Código: La Entidad Estudiante (`Estudiante.java`)

```java
@Entity
@Table(name = "estudiantes")
@NamedStoredProcedureQuery(
    name = "Estudiante.obtenerPromedio",
    procedureName = "SP_OBTENER_PROMEDIO",
    parameters = {
        @StoredProcedureParameter(
            mode = ParameterMode.IN, 
            name = "p_estudiante_id", type = Integer.class),
        @StoredProcedureParameter(
            mode = ParameterMode.OUT, 
            name = "p_promedio", type = Double.class)
    }
)
public class Estudiante {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;
    private String nombre;
    private String carnet;
    private boolean activo;
    // Constructor, getters y setters...
}
```

# Código: El Repositorio (`EstudianteRepository.java`)

```java
@Repository
public interface EstudianteRepository 
        extends JpaRepository<Estudiante, Integer> {

    // Ejecutar procedimiento almacenado
    @Procedure(name = "Estudiante.obtenerPromedio")
    Double obtenerPromedioEstudiante(
        @Param("p_estudiante_id") Integer estudianteId
    );

    // Consulta paginada personalizada
    Page<Estudiante> findByActivo(
        boolean activo, 
        Pageable pageable
    );
}
```

# Código: El Servicio Paginado (`EstudianteService.java`)

```java
@Service
public class EstudianteService {
    @Autowired
    private EstudianteRepository repository;

    @Transactional(readOnly = true)
    public Page<Estudiante> listarActivosPaginados(
        int pagina, int tamano
    ) {
        Pageable controlPaginacion = PageRequest.of(
            pagina, 
            tamano, 
            Sort.by("nombre").ascending()
        );
        return repository.findByActivo(true, controlPaginacion);
    }
}
```

# Trampas Comunes en Persistencia

* **Problema N+1 SELECT:** Ocurre al cargar colecciones de datos ansiosamente (`Eager`), generando $N$ consultas adicionales para obtener los elementos asociados de la lista.
  * *Solución:* Usar carga perezosa (`Lazy`) y `JOIN FETCH` o `@EntityGraph`.
* **Excepción `LazyInitializationException`:** Intentar leer una propiedad perezosa fuera de una sesión transaccional activa de Hibernate.
  * *Solución:* Usar `@Transactional` en los métodos de servicio.
* **Transaccionalidad en Procedimientos:** Llamadas a procedimientos almacenados que modifican datos sin transacción activa fallarán.
  * *Solución:* Garantizar la presencia de `@Transactional`.
