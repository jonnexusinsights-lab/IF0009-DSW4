La Capa de Controladores (@RestController)

  • Definición de Entrada al Sistema:
    • Responsable de recibir las solicitudes de red del cliente.
    • Valida formalmente la estructura y contenido de los datos (DTOs).
    • Delega la lógica de negocio a la capa de servicios.
    • Construye y retorna la respuesta de red correspondiente.
  • Componente de Spring Boot:
    • Declarado con la anotación estereotipo @RestController.
    • Combina @Controller (manejo de endpoints) y @ResponseBody (retorno directo en formato JSON).

Fundamentos de HTTP y Verbos de Red

  • HTTP es Stateless (Sin Estado):
    • Cada petición-respuesta es independiente. No se guarda sesión local en RAM.
  • Verbos HTTP Principales:
    • GET: Recupera recursos. Operación segura e idempotente.
    • POST: Registra nuevos recursos en base de datos.
    • PUT: Reemplaza la totalidad del recurso indicado. Idempotente.
    • PATCH: Modificación parcial de los campos de un recurso.
    • DELETE: Elimina permanentemente el recurso del servidor. Idempotente.

Semántica de Códigos de Respuesta HTTP

  • 2xx (Éxito):
    • 200 OK (Operación exitosa), 201 Created (Creación de recurso exitosa), 204 No Content (Éxito sin datos de retorno).
  • 4xx (Error del Cliente):
    • 400 Bad Request (Datos inválidos o nulos).
    • 401 Unauthorized (Autenticación ausente), 403 Forbidden (Acceso denegado por roles).
    • 404 Not Found (Recurso no encontrado), 409 Conflict (Violación de unicidad).
  • 5xx (Error de Servidor):
    • 500 Internal Error (Excepción no controlada), 503 Unavailable (Caída de red).

De Arquitectura SOA a Microservicios

  • SOA (Arquitectura Orientada a Servicios):
    • Tradicionalmente pesada. Integra aplicaciones usando buses de servicios (ESB) y mensajes XML grandes sobre SOAP.
  • Microservicios y Desacoplamiento:
    • Descompone la aplicación en servicios autónomos e independientes.
    • Cada microservicio gestiona su base de datos.
    • Comunicación ágil utilizando APIs RESTful y formato liviano JSON.
    • Permite desacoplar el desarrollo del backend de clientes web (Angular) o móviles.

Trampas Comunes en Controladores

  • Ignorar Códigos HTTP (Retornar siempre 200 OK):
    • Retornar un body de error con código HTTP 200. Esto confunde a los clientes de red (Angular) e impide procesar fallas por interceptores.
  • Exposición Directa de Entidades JPA:
    • Provoca bucles de mapeo JSON infinito si hay relaciones @ManyToMany o @OneToMany.
  • Ignorar Validación Automática:
    • Omitir @Validated o @Valid en el @RequestBody, ingresando registros con campos inválidos o nulos.
