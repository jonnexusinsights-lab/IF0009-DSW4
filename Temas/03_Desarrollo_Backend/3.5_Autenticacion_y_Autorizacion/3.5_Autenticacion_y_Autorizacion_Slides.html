Fundamentos de Seguridad: Autenticación vs Autorización

  • Autenticación (Authentication):
    • Verificación inequívoca de la identidad presentada por el usuario.
    • Responde a: ¿Quién es usted?
    • Mecanismos: Credenciales (Usuario/Password), Factores Biométricos, Certificados.
  • Autorización (Authorization):
    • Evaluación de permisos y privilegios asignados al sujeto autenticado.
    • Responde a: ¿Qué operaciones tiene permitido ejecutar?
    • Mecanismos: RBAC (Role-Based Access Control), ABAC (Attribute-Based).

Arquitectura de Spring Security 6

  • SecurityContextHolder: Almacena el SecurityContext en el hilo actual (ThreadLocal).

  • UserDetailsService: Interfaz para recuperar datos de usuarios desde la BD.
  • PasswordEncoder: Encriptación salada unidireccional (BCrypt).

Creación Explícita: UserDetailsService & BCrypt

@Service
public class CustomUserDetailsService implements UserDetailsService {

    private final UsuarioRepository usuarioRepository;

    @Override
    public UserDetails loadUserByUsername(String username) {
        Usuario u = usuarioRepository.findByUsername(username)
            .orElseThrow(() -> new UsernameNotFoundException("No existe"));

        Set<GrantedAuthority> authorities = u.getRoles().stream()
            .map(r -> new SimpleGrantedAuthority(r.getNombreRol()))
            .collect(Collectors.toSet());

        return new User(u.getUsername(), u.getPassword(), u.isActivo(), 
                        true, true, true, authorities);
    }
}

Configuración Explícita: SecurityFilterChain

@Configuration
@EnableWebSecurity
@EnableMethodSecurity(prePostEnabled = true)
public class SecurityConfig {

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder(10);
    }

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        return http
            .csrf(csrf -> csrf.disable())
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**").permitAll()
                .requestMatchers(HttpMethod.GET, "/api/envios/**")
                    .hasAnyRole("ADMIN", "OPERADOR", "CONDUCTOR")
                .requestMatchers("/api/vehiculos/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            .build();
    }
}

Autorización Declarativa con @PreAuthorize

  • Permite validar privilegios directamente sobre métodos de controladores o servicios. 
@RestController
@RequestMapping("/api/admin/flotas")
public class FlotaController {

    @DeleteMapping("/{vehiculoId}")
    @PreAuthorize("hasRole('ADMIN')")
    public ResponseEntity<Void> darDeBajaVehiculo(@PathVariable Integer vehiculoId) {
        envioService.darDeBajaVehiculo(vehiculoId);
        return ResponseEntity.noContent().build();
    }
}

Trampas Comunes y Buenas Prácticas

  • Contraseñas en Texto Plano: Prohibidas. Use BCryptPasswordEncoder(10).
  • Prefijo de Roles: hasRole('ADMIN') exige que el permiso en BD sea ROLE_ADMIN.
  • CSRF en APIs REST: Deshabilite CSRF (csrf.disable()) únicamente en APIs REST stateless con tokens JWT.
