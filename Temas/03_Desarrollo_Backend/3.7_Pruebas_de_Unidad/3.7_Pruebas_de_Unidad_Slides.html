Integración con Apache Maven

Gestión de dependencias y ejecución automatizada en el ciclo de construcción:
  • spring-boot-starter-test:
    • Incluye JUnit Jupiter, Mockito, AssertJ, Hamcrest y Spring Test.
    • Se declara con el ámbito <scope>test</scope> para no contaminar el JAR productivo.
  • maven-surefire-plugin:
    • Ejecuta la fase mvn test.
    • Escanea clases *Test.java y genera reportes XML/texto en target/surefire-reports/. 
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-test</artifactId>
    <scope>test</scope>
</dependency>

Arquitectura Modular de JUnit 5

$$\text{JUnit 5} = \text{JUnit Platform} + \text{JUnit Jupiter} + \text{JUnit Vintage}$$
  • JUnit Platform: Infraestructura base para lanzar motores de prueba en la JVM. Conecta IDEs (VS Code, IntelliJ) y herramientas de build (Maven, Gradle).
  • JUnit Jupiter: Nuevo modelo de programación y extensión. Aporta anotaciones avanzadas, pruebas parametrizadas y el motor principal TestEngine.
  • JUnit Vintage: Motor de compatibilidad para ejecutar pruebas legacy de JUnit 3 y 4.

Anotaciones Principales de JUnit Jupiter

  • @Test: Identifica un método de prueba automatizada.
  • @BeforeEach / @AfterEach: Se ejecuta antes o después de cada prueba (reseteo de estado/mocks).
  • @DisplayName("..."): Etiqueta descriptiva para reportes de Maven y consola.
  • @Disabled: Desactiva una prueba temporalmente.
  • @ParameterizedTest: Ejecuta el mismo test con múltiples fuentes de datos (@ValueSource, @CsvSource).

Aserciones Avanzadas en JUnit Jupiter

  • Aserciones Agrupadas (assertAll):
    • Evalúa múltiples condiciones y reporta todas las fallas simultáneamente sin detener la ejecución en la primera.

Dobles de Prueba con Mockito 5.x

Aislamiento de la lógica de negocio sin cargar Spring ni bases de datos:
  • @ExtendWith(MockitoExtension.class): Integra el motor ligero de Mockito en JUnit Jupiter.
  • @Mock: Crea una implementación simulada e inerte de una dependencia (ej. Repository).
  • @InjectMocks: Instancia la clase bajo prueba e inyecta los mocks automáticamente.
  • when(mock.metodo()).thenReturn(valor): Programa respuestas controladas.

Pruebas Parametrizadas en JUnit Jupiter + Mockito

@ExtendWith(MockitoExtension.class)
@DisplayName("Pruebas Unitarias de VehiculoService")
class VehiculoServiceTest {

    @Mock
    private VehiculoRepository vehiculoRepository;

    @InjectMocks
    private VehiculoService vehiculoService;

    @ParameterizedTest
    @ValueSource(longs = {99L, 100L, 500L})
    @DisplayName("Debe lanzar excepción para múltiples IDs inexistentes")
    void obtenerPorId_IdInexistente_LanzaExcepcion(Long idInexistente) {
        when(vehiculoRepository.findById(idInexistente)).thenReturn(Optional.empty());

        assertThrows(RecursoNoEncontradoException.class,
            () -> vehiculoService.obtenerPorId(idInexistente));

        verify(vehiculoRepository, times(1)).findById(idInexistente);
    }
}

Pruebas de Rebanada en Controladores REST (@WebMvcTest)

Aísla la capa web probando la serialización JSON y mapeos HTTP sin arrancar Tomcat: 
@WebMvcTest(VehiculoController.class)
@DisplayName("Pruebas de Rebanada en Controlador REST")
class VehiculoControllerTest {

    @Autowired
    private MockMvc mockMvc;

    @MockBean
    private VehiculoService vehiculoService;

    @Test
    void obtenerPorId_Responde200OkYJson() throws Exception {
        given(vehiculoService.obtenerPorId(1L)).willReturn(new Vehiculo(1L, "SJB-9876"));

        mockMvc.perform(get("/api/v1/vehiculos/1").accept(MediaType.APPLICATION_JSON))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.placa").value("SJB-9876"));
    }
}

Trampas Comunes y Antipatrones

  • Mezclar Importaciones de JUnit 4 y JUnit Jupiter:
    • Importar org.junit.Test en lugar de org.junit.jupiter.api.Test.
  • Omisión del Ámbito <scope>test</scope> en Maven:
    • Empaquetar librerías de testeo dentro del artefacto .jar ejecutable de producción.
  • Uso Indiscriminado de @SpringBootTest para Pruebas Unitarias:
    • Carga innecesaria del contexto completo de Spring; eleva los tiempos de ejecución de milisegundos a segundos.
