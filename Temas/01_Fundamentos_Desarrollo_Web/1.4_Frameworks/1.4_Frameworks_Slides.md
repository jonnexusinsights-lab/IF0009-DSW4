## 1. Framework vs. Biblioteca (Library)

* **Biblioteca (Library):**
  * Conjunto de clases y funciones empaquetadas.
  * Su código tiene el control y decide cuándo llamarlas.
  * Ejemplo: `Gson` para serializar JSON.
* **Framework (Marco de Trabajo):**
  * Esqueleto arquitectónico que prescribe la estructura del sistema.
  * El framework invoca a su código en puntos predefinidos.
  * Ejemplo: `Spring Boot` para APIs empresariales.
* <span class="highlight">Inversión de Control (IoC):</span> El flujo de control se delega del código del programador hacia la plataforma/framework.

## Inversión de Control y Inyección de Dependencias

```text
Aproximación Imperativa Tradicional (Biblioteca):
[Su Código] ─── new ServicioEmail() ───> Instancia de Email

Aproximación Declarativa Moderna (Framework / DI):
[Contenedor Spring (IoC)] ─── Instancia y mantiene Bean ───> [Su Código]
                             (Inyecta automáticamente vía @Autowired)
```

* **Inyección de Dependencias (DI):** Patrón que implementa IoC, pasando a una clase sus colaboradoras externas de manera pasiva.

## 2. Criterios de Selección de Stacks Tecnológicos

La selección de tecnologías en la empresa responde a variables racionales:

* **Arquitectura y Rendimiento:** Consumo de recursos de infraestructura, concurrencia nativa de hilos y velocidad de procesamiento.
* **Curva de Aprendizaje y Talento:** Costo y factibilidad de reclutamiento de desarrolladores en el mercado local.
* **Comunidad y Respaldo:** Frecuencia de parches de seguridad y soporte corporativo estable (Oracle, Microsoft, Google).
* **Costo Total de Propiedad (TCO):** Costo de servidores en la nube y licencias asociadas.

## Inyección de Dependencias en Spring Boot (Java)

```java
@Service // El framework toma control del ciclo de vida de esta clase
class ServicioEmail implements ServicioNotificaciones {
    public void enviarMensaje(String destino, String msg) { ... }
}

@Component
class GestorUsuarios {
    private final ServicioNotificaciones servicio;

    @Autowired // Spring busca en su contenedor el Bean compatible e inyecta la instancia
    public GestorUsuarios(ServicioNotificaciones servicio) {
        this.servicio = servicio;
    }
}
```

## Trampas Comunes (Gotchas)

* **Uso inapropiado de `new`:**
  * Si inicializa componentes administrados usando `new`, rompe la inversión de control y anula las capacidades decorativas y transaccionales del framework.
  * *Solución:* Use inyección de constructor o `@Autowired`.
* **Dependencias Circulares:**
  * Ocurre cuando dos clases se inyectan recursivamente una a la otra (A -> B -> A). Spring aborta el inicio con un fallo de contexto.
  * *Solución:* Refactorice extrayendo la lógica común a una clase intermedia.
