🐦 Flutter: De Principiante a Avanzado

Desarrollo Móvil Multiplataforma

Framework: Flutter (Google) Lenguaje: Dart 3

¿Por qué Flutter es Diferente?

A diferencia de otros frameworks multiplataforma (como React Native o Ionic), Flutter no usa puentes (bridges) ni dibuja elementos HTML. Flutter utiliza su propio motor gráfico de C++ (Skia / Impeller). Flutter le dice al dispositivo móvil: "Dame un lienzo en blanco (canvas), yo me encargo de dibujar cada píxel de los botones y textos a 120 FPS." Esto garantiza que la app se vea exactamente igual en un iPhone y en un Android, con rendimiento verdaderamente nativo.

🎯 El Lenguaje: Dart 3

El lenguaje base es Dart, optimizado fuertemente para UI. Características modernas:
  • Null Safety Estricto: Es imposible tener un NullPointerException inesperado. Si una variable puede ser nula, debes declararla con ?.
  • Records (Tuplas): Devolver múltiples valores es muy sencillo.
  • Pattern Matching: 
var (nombre, edad) = obtenerUsuario();

String cat = switch(edad) {
  < 18 => 'Menor',
  >= 18 => 'Adulto'
};

🌳 Todo es un Widget

En la arquitectura de Flutter, literalmente todo es un Widget.
  • Text('Hola') es un Widget.
  • Padding(...) es un Widget que envuelve a otro.
  • Center(...) es un Widget de posicionamiento.
Se construyen interfaces anidando Widgets en forma de árbol (Widget Tree).

Estado: Stateless vs Stateful

  • StatelessWidget: Nace, se dibuja, y nunca cambia. (Ej. un ícono estático).
  • StatefulWidget: Tiene un objeto de estado interno (State). Si ejecutas la función setState(), Flutter redibujará esa porción específica de la pantalla. (Ej. un contador que sube de 0 a 1).

Layouts Básicos:

  • Row: Organiza a sus hijos de izquierda a derecha.
  • Column: Organiza a sus hijos de arriba hacia abajo.

🧠 State Management (Gestión de Estado Avanzada)

setState() no es escalable para apps empresariales (causa código espagueti y redibuja vistas enteras innecesariamente). Se debe separar la Lógica de Negocio de la UI usando Arquitecturas de Estado:
  1. Provider: Recomendado para iniciar. Usa ChangeNotifier. La vista "escucha" los cambios de una clase.
  2. Riverpod: Evolución de Provider. Seguro en tiempo de compilación.
  3. BLoC (Business Logic Component): Estándar Enterprise. Basado estrictamente en Streams (Eventos entran, Estados salen).

⚡ Tópicos Avanzados: Multihilo y Nativo

Dart es Single-Thread (Event Loop). Las llamadas HTTP async/await no bloquean la UI, pero el cómputo matemático pesado (ej. desencriptar miles de registros locales) sí lo hará, congelando la animación.
  • Isolates: Es la respuesta de Dart para el multihilo real. Permite abrir un hilo físico separado del procesador (sin memoria compartida, se comunican por mensajes).
  • Method Channels (Platform Channels): Si necesitas acceder al Bluetooth nativo de Android usando código Kotlin desde Flutter, usas un canal de comunicación para disparar comandos entre Dart y Kotlin/Swift.

🏁 Conclusión: La Curva de Aprendizaje

  1. Principiante: Entender el árbol de Widgets (Row, Column, Stateless).
  2. Intermedio: Llamadas HTTP (REST), Serialización JSON y Navegación.
  3. Avanzado: Arquitectura de Estado estricta (BLoC / Riverpod), Animaciones fluidas, Inyección de Dependencias, Tests y Method Channels nativos.
