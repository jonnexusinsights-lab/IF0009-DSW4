# ¿Por qué Importa un Sistema de Diseño?

* **Consistencia Cognitiva:** Reduce la curva de aprendizaje de la persona usuaria.
* **Escalabilidad Visual:** Un cambio de tema centralizado impacta toda la aplicación.
* **Accesibilidad (A11y):** Garantiza relaciones de contraste que cumplen WCAG AAA.
* **Fidelidad Nativa:** Ofrece comportamientos ergonómicos acordes a Android e iOS.

---

# Material Design 3 (Material You)

* **Estándar Oficial:** Habilitado por defecto en Flutter (`useMaterial3: true`).
* **Algoritmo HCT:** *Hue, Chroma, Tone* extrae 30+ tonos de un único color semilla.
* **Elevación Tonal:** Reemplaza sombras difusas por tintes de superficie (`surfaceTintColor`).
* **Nuevos Widgets:** `FilledButton`, `NavigationBar`, `SegmentedButton`, `FilterChip`.

---

# Configuración de Tema Centralizado M3

```dart
class AppTheme {
  static const Color _seedColor = Color(0xFF003865); // Azul UCR

  static ThemeData get lightTheme => ThemeData(
    useMaterial3: true,
    colorScheme: ColorScheme.fromSeed(
      seedColor: _seedColor,
      brightness: Brightness.light,
    ),
    appBarTheme: const AppBarTheme(centerTitle: true),
    cardTheme: CardTheme(
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(16.0),
      ),
    ),
  );
}
```

# Jerarquía Tipográfica M3 (`TextTheme`)

* **Display (L, M, S):** Textos gigantes de impacto en landing o splash screens.
* **Headline (L, M, S):** Títulos de pantallas y secciones principales.
* **Title (L, M, S):** Encabezados de tarjetas, diálogos y elementos de lista.
* **Body (L, M, S):** Texto de lectura continua y descripciones detalladas.
* **Label (L, M, S):** Rótulos de botones, tags, badges y pestañas de navegación.

---

# Sistema Cupertino (Apple HIG)

* **Estética Apple:** Translucidez, desenfoque dinámico (*blur*) y bordes finos.
* **Navegación:** `CupertinoNavigationBar` con títulos centrados y botón Chevron con texto.
* **Físicas:** Desplazamiento elástico nativo con `BouncingScrollPhysics`.
* **Selectores:** Selectores cilíndricos de tipo rueda con `CupertinoPicker`.

# Enfoque Adaptativo Multiplataforma

```dart
// 1. Constructores adaptativos nativos de Flutter
Switch.adaptive(
  value: isEnabled,
  onChanged: (val) => setState(() => isEnabled = val),
);

// 2. Iconos adaptativos segun el SO
Icon(Icons.adaptive.share);
Icon(Icons.adaptive.arrow_back);

// 3. Indicadores de progreso contextuales
CircularProgressIndicator.adaptive();
```

# Diálogo Adaptativo: Implementación

```dart
Widget build(BuildContext context) {
  final isApple = !kIsWeb && (Platform.isIOS || Platform.isMacOS);
  
  if (isApple) {
    return CupertinoAlertDialog(
      title: Text(title),
      content: Text(message),
      actions: [
        CupertinoDialogAction(child: Text('OK'), onPressed: onConfirm),
      ],
    );
  }
  return AlertDialog(
    title: Text(title),
    content: Text(message),
    actions: [
      FilledButton(child: Text('OK'), onPressed: onConfirm),
    ],
  );
}
```

# Trampas Comunes y Antipatrones

* **Hardcoding de Colores:** Usar `Colors.blue` directo en lugar de `Theme.of(context).colorScheme.primary`.
* **Ruptura de Dark Mode:** Textos que no contrastan al conmutar temas.
* **Uso de `dart:io` sin `kIsWeb`:** Detona un error fatal al compilar para la Web.
* **Mezcla Inadecuada de Árboles:** Usar widgets Material dentro de `CupertinoApp` sin contenedor `Material`.
