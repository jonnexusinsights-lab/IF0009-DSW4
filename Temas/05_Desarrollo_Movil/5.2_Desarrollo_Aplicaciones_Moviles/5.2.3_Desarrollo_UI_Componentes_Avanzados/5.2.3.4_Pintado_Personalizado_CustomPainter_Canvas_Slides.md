# ¿Cuándo Usar `CustomPainter`?

* **Límites de Widgets Preconstruidos:** Gráficos estadísticos, diales o tacómetros.
* **Control Pixel-Perfect:** Ilustraciones vectoriales matemáticas y diagramas en tiempo real.
* **Eficiencia Gráfica:** Reduce decenas de widgets anidados a una única instrucción de renderizado.
* **Integración Directa:** Habla directamente con el motor gráfico en C++ de Flutter.

# El Contrato de `CustomPainter`

* **`paint(Canvas canvas, Size size)`:**
  * Recibe el lienzo de dibujo y las dimensiones calculadas por el padre.
  * Ejecuta comandos gráficos inmediatos (`drawCircle`, `drawArc`, `drawPath`).
* **`shouldRepaint(covariant CustomPainter oldDelegate)`:**
  * Compara la configuración actual contra la previa.
  * Si retorna `false`, reutiliza la textura en GPU sin re-ejecutar `paint()`.
  * Clave crítica para sostener 60 a 120 FPS.

---

# Sistema Cartesiano 2D en Flutter

* **Origen `(0, 0)`:** Esquina superior izquierda del widget.
* **Eje X:** Se incrementa positivamente hacia la **derecha**.
* **Eje Y:** Se incrementa positivamente hacia **abajo**.
* **Centro Geométrico:** `Offset(size.width / 2, size.height / 2)`.
* **Regla Cardinal:** Todo trazo debe calcularse relativo a `size` para ser responsivo.

---

# Pincel (`Paint`) y Trazo Vectorial (`Path`)

* **Propiedades de `Paint`:**
  * `style: PaintingStyle.stroke` (contorno) o `.fill` (relleno).
  * `strokeWidth`: Grosor en píxeles lógicos del trazado.
  * `strokeCap: StrokeCap.round`: Terminaciones suaves y redondeadas.
  * `shader`: Gradientes lineales, radiales o de barrido cónico.
* **Capacidades de `Path`:**
  * `moveTo(x, y)` y `lineTo(x, y)`: Trazado de polígonos.
  * `quadraticBezierTo()`: Curvas suaves guiadas por puntos de atracción.

# Implementación: Gauge Circular

```dart
class RadialGaugePainter extends CustomPainter {
  final double percentage;
  final Color activeColor;

  RadialGaugePainter({required this.percentage, required this.activeColor});

  @override
  void paint(Canvas canvas, Size size) {
    final center = Offset(size.width / 2, size.height / 2);
    final radius = (size.width - 20) / 2;
    final paint = Paint()
      ..color = activeColor
      ..style = PaintingStyle.stroke
      ..strokeWidth = 14.0
      ..strokeCap = StrokeCap.round;

    // Angulo inicial arriba (-PI/2) y barrido proporcional
    canvas.drawArc(
      Rect.fromCircle(center: center, radius: radius),
      -math.pi / 2,
      2 * math.pi * percentage,
      false,
      paint,
    );
  }

  @override
  bool shouldRepaint(RadialGaugePainter old) => old.percentage != percentage;
}
```

# Trampas Comunes en Dibujo 2D

* **Instanciar Objetos en `paint()`:** Crear `Paint()` en cada frame satura el Garbage Collector.
* **Retornar `true` ciegamente en `shouldRepaint`:** Deshabilita el caché de GPU y drena la batería.
* **Coordenadas Absolutas:** Usar valores duros como `Offset(200, 200)` que se deforman en otros dispositivos.
* **Ángulos en Grados:** Olvidar que las funciones trigonométricas de Flutter requieren **radianes** ($\text{rad} = \text{grados} \times \frac{\pi}{180}$).
