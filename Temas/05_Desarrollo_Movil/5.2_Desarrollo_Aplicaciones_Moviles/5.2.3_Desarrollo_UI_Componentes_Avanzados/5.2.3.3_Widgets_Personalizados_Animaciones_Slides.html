  • Aislar capas de repintado en la GPU mediante RepaintBoundary.

Composición sobre Herencia

  • Antipatrón de Herencia: Jerarquías profundas y frágiles de botones o tarjetas.
  • Paradigma de Flutter: Ensamblaje modular de widgets atómicos de propósito único.
  • Inmutabilidad: Los widgets son configuraciones ultraligeras y efímeras.
  • Separación de Responsabilidades: Gestos (GestureDetector), diseño (Row), color (Container).

Optimización con const y RepaintBoundary

  • Canonicalización const:
    • Reutiliza la misma instancia en memoria en tiempo de compilación.
    • Flutter omite por completo invocar build() en sub-árboles constantes.
  • RepaintBoundary:
    • Crea una textura independiente (Layer) en el búfer de la GPU.
    • Si un spinner gira a 60 FPS, no repinta las listas estáticas adyacentes.
    • Reduce drásticamente la carga de CPU y el consumo de batería.

Animaciones Implícitas vs Explícitas

| Criterio | Implícitas | Explícitas | | :--- | :--- | :--- | | Controlador | Sin AnimationController | Con AnimationController | | Disparador | Cambio en setState() | forward(), reverse(), repeat() | | Complejidad | Baja (declarativo) | Alta (control por fotograma) | | Ejemplos | AnimatedContainer, AnimatedOpacity | AnimatedBuilder, RotationTransition |

Implementación: Animación Explícita

class _PulseWidgetState extends State<PulseWidget>
    with SingleTickerProviderStateMixin {
  late final AnimationController _controller;
  late final Animation<double> _scaleAnimation;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      vsync: this,
      duration: const Duration(milliseconds: 1000),
    )..repeat(reverse: true);

    _scaleAnimation = Tween(begin: 1.0, end: 1.2).animate(
      CurvedAnimation(parent: _controller, curve: Curves.easeInOut),
    );
  }

  @override
  void dispose() {
    _controller.dispose(); // Obligatorio para evitar leaks
    super.dispose();
  }
}

Optimización con AnimatedBuilder

RepaintBoundary(
  child: AnimatedBuilder(
    animation: _scaleAnimation,
    // El widget costoso se pasa como 'child' estático
    child: ExpensiveLogoWidget(),
    builder: (context, child) {
      // Solo el Transform se re-ejecuta en cada frame (60 FPS)
      return Transform.scale(
        scale: _scaleAnimation.value,
        child: child, // Reutiliza la instancia existente
      );
    },
  ),
)

Transiciones de Elementos Compartidos (Hero)

  • Continuidad Visual: Anima un elemento desde una pantalla A hacia una pantalla B.
  • Etiqueta Única (tag): Ambas pantallas comparten el mismo identificador.
  • Vuelo Automático: Flutter orquestará la interpolación de tamaño y posición en la ruta. 
// En Pantalla Origen y Pantalla Destino:
Hero(
  tag: 'product-avatar-${item.id}',
  child: Image.network(item.imageUrl),
)

Trampas Comunes en Animaciones

  • Fugas de Memoria: Olvidar invocar dispose() en el AnimationController.
  • Uso de setState en listeners de animación: Reconstruye toda la pantalla a 60 FPS en lugar de usar AnimatedBuilder.
  • Abuso de RepaintBoundary: Colocarlo en cada ítem de una lista satura la memoria VRAM de la GPU.
  • Curvas Inadecuadas: Usar animaciones lineales (Curves.linear) que se perciben mecánicas y poco naturales.
