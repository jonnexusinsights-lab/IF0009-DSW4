# Subtema 5.2.7: Entornos (Flavors), Firmado de Binarios y Preparación para Tiendas

Este subtema abarca:
- Configuración de Flavors / Entornos de ejecución (Dev, Staging, Prod).
- Personalización de App Icons (`flutter_launcher_icons`) y Native Splash Screens (`flutter_native_splash`).
- Generación de claves Java Keystore / Upload Keys.
- Firmado y compilación de binarios en release: Android App Bundle (`.aab`) y APK (`.apk`).
- Generación y firmado de paquetes iOS (`.ipa`) y perfiles de aprovisionamiento (*Provisioning Profiles*).
- Checklist y buenas prácticas para publicación oficial en Google Play Console y Apple App Store.
