Modelos Fuertemente Tipados (DTOs)

class IncidenciaDTO {
  final int? id;
  final String titulo;
  final double latitud;

  IncidenciaDTO({this.id, required this.titulo, required this.latitud});

  factory IncidenciaDTO.fromJson(Map<String, dynamic> json) {
    return IncidenciaDTO(
      id: json['id'] as int?,
      titulo: json['titulo'] as String? ?? 'Sin título',
      latitud: (json['latitud'] as num).toDouble(),
    );
  }
}
  • Previene excepciones TypeError en producción.
  • Maneja de forma segura valores nulos y conversiones numéricas.

Almacenamiento Seguro de Tokens JWT

import 'package:flutter_secure_storage/flutter_secure_storage.dart';

class AuthStorageService {
  final _storage = const FlutterSecureStorage(
    aOptions: AndroidOptions(encryptedSharedPreferences: true),
  );

  Future<void> saveToken(String token) async =>
      await _storage.write(key: 'jwt_token', value: token);

  Future<String?> getToken() async =>
      await _storage.read(key: 'jwt_token');

  Future<void> deleteToken() async =>
      await _storage.delete(key: 'jwt_token');
}

Servicio Cliente RESTful en Dart

Future<List<IncidenciaDTO>> obtenerIncidencias(String baseUrl) async {
  final token = await authStorage.getToken();
  final url = Uri.parse('$baseUrl/api/v1/incidencias');

  final response = await http.get(
    url,
    headers: {
      'Content-Type': 'application/json',
      if (token != null) 'Authorization': 'Bearer $token',
    },
  ).timeout(const Duration(seconds: 10));

  if (response.statusCode == 200) {
    final List data = jsonDecode(utf8.decode(response.bodyBytes));
    return data.map((e) => IncidenciaDTO.fromJson(e)).toList();
  }
  throw Exception('Falla HTTP: ${response.statusCode}');
}

Resiliencia: Timeouts y Manejo de Red

  • utf8.decode(response.bodyBytes):
    • Protege caracteres acentuados y caracteres especiales en español.
  • timeout(Duration(seconds: 10)):
    • Evita bloqueos visuales en zonas con pérdida de cobertura.
  • Manejo de Excepciones:
    • SocketException: Sin conexión física o servidor apagado.
    • TimeoutException: Latencia excesiva de red.
    • Códigos 401 Unauthorized: Forzar cierre de sesión / refresh token.

Trampa Crítica: Loopback en Emuladores

  • ❌ http://localhost:8080 apunta al emulador Android mismo.
  • ✅ En emulador Android oficial use:
http://10.0.2.2:8080
  • ✅ En dispositivo físico depurado por USB:
Use la IP de su red local (ej. http://192.168.1.15:8080)
  • Permiso de Tráfico no Seguro en Android (AndroidManifest.xml):
android:usesCleartextTraffic="true" (solo para desarrollo local).
