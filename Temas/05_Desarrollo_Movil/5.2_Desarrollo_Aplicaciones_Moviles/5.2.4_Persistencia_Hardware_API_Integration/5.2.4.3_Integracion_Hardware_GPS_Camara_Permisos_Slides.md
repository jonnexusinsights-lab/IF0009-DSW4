# El Modelo de Seguridad Sandbox

* **Aislamiento Estricto:** Ninguna app accede a sensores sin autorización.
* **Fases Obligatorias de Integración:**
  1. **Declaración Estática:** Permisos en `AndroidManifest.xml` e `Info.plist`.
  2. **Verificación de Sensor:** Comprobar si el GPS está físicamente activo.
  3. **Consentimiento Dinámico:** Solicitar permiso con diálogo del SO.
  4. **Degradación Elegante:** Guiar al usuario si el permiso fue denegado.

---

# Configuración Nativa en Android e iOS

* **Android (`AndroidManifest.xml`):**
  ```xml
  <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
  <uses-permission android:name="android.permission.CAMERA" />
  ```
* **iOS (`Info.plist`):** Cadenas descriptivas obligatorias:
  * `NSLocationWhenInUseUsageDescription`: Justificación de GPS.
  * `NSCameraUsageDescription`: Justificación de uso de la cámara.

# Geolocalización Satelital con `geolocator`

```dart
Future<Position> obtenerCoordenadas() async {
  bool habilitado = await Geolocator.isLocationServiceEnabled();
  if (!habilitado) throw Exception('Active el GPS del teléfono.');

  LocationPermission permiso = await Geolocator.checkPermission();
  if (permiso == LocationPermission.denied) {
    permiso = await Geolocator.requestPermission();
    if (permiso == LocationPermission.denied) {
      throw Exception('Permiso denegado.');
    }
  }
  return await Geolocator.getCurrentPosition(
    locationSettings: const LocationSettings(accuracy: LocationAccuracy.high),
  );
}
```

# Captura de Fotos con `image_picker`

```dart
final ImagePicker _picker = ImagePicker();

Future<File?> capturarFoto() async {
  final XFile? foto = await _picker.pickImage(
    source: ImageSource.camera,
    maxWidth: 1920,
    maxHeight: 1080,
    imageQuality: 80, // Compresión visualmente imperceptible
  );
  if (foto == null) return null;
  return File(foto.path);
}
```

# Envío Multipart a Spring Boot 3

```dart
Future<bool> enviarReporte(String url, String token, File foto) async {
  final req = http.MultipartRequest('POST', Uri.parse(url));
  req.headers['Authorization'] = 'Bearer $token';

  req.fields['titulo'] = 'Falla en tubería central';
  req.fields['latitud'] = '9.9322';
  req.fields['longitud'] = '-84.0795';

  req.files.add(await http.MultipartFile.fromPath('foto', foto.path));
  final response = await req.send();
  return response.statusCode == 201;
}
```

# Buenas Prácticas de Hardware Móvil

* **Manejo de Permisos Permanentemente Denegados:**
  * Si el estado es `deniedForever`, usar `openAppSettings()` para redirigir al menú nativo de ajustes del teléfono.
* **Simulación en Emulador de Android:**
  * Enviar coordenadas ficticias usando el panel lateral `Extended Controls > Location`.
* **Dispositivo Físico:**
  * Validar siempre la respuesta del sensor ante movimiento y cielo cubierto.
