# Niveles de Almacenamiento en el Dispositivo

| Mecanismo | Uso Recomendado | Características |
|---|---|---|
| **SharedPreferences** | Preferencias de usuario, flags, tema | Clave-Valor plano |
| **sqflite (SQLite)** | Modelos de negocio, tablas, relaciones | ANSI SQL relacional, transacciones ACID |
| **FlutterSecureStorage** | Tokens JWT, llaves privadas | Bóveda cifrada (Keystore/Keychain) |

# Principios del Patrón Offline-First

* **La base de datos local es la fuente de verdad (Single Source of Truth):**
  * La interfaz consulta SQLite, nunca espera al backend para renderizar.
* **Escrituras Inmediatas:**
  * Guardado local con bandera `is_synced = 0`.
* **Sincronización en Segundo Plano:**
  * Al detectar red, se consumen los pendientes y se envían al servidor.
* **Resolución de Conflictos:**
  * Identificadores UUID del cliente y actualización a `is_synced = 1`.

# DatabaseHelper Singleton en Dart 3

```dart
class DatabaseHelper {
  static final DatabaseHelper instance = DatabaseHelper._init();
  static Database? _database;
  DatabaseHelper._init();

  Future<Database> get database async {
    if (_database != null) return _database!;
    _database = await _initDB('fieldtech_local.db');
    return _database!;
  }

  Future<Database> _initDB(String filePath) async {
    final dbPath = await getDatabasesPath();
    final path = join(dbPath, filePath);
    return await openDatabase(path, version: 1, onCreate: _createDB);
  }
}
```

# Sincronización Resiliente con Spring Boot

```dart
Future<int> sincronizarPendientes(String token, String url) async {
  final pendientes = await dbHelper.obtenerNoSincronizadas();
  int count = 0;

  for (final row in pendientes) {
    try {
      final res = await http.post(
        Uri.parse('$url/api/v1/incidencias'),
        headers: {'Content-Type': 'application/json', 'Authorization': 'Bearer $token'},
        body: jsonEncode(row),
      );
      if (res.statusCode == 200 || res.statusCode == 201) {
        await dbHelper.marcarComoSincronizado(row['id'] as int);
        count++;
      }
    } catch (_) { break; } // Pausar si se pierde la red
  }
  return count;
}
```

# Buenas Prácticas y Prevención de Trampas

* **No guardar imágenes en SQLite como BLOB grande:**
  * Guardar el archivo en el sistema de archivos del teléfono (`path_provider`).
  * Guardar en SQLite únicamente la ruta de archivo local en formato `TEXT`.
* **Evitar bloqueos de base de datos:**
  * Mantener siempre una única instancia abierta (patrón Singleton).
* **Manejo de Idempotencia:**
  * Asignar un `client_uuid` a cada entidad para evitar duplicados si la red cae durante la respuesta HTTP.
