# Subtema 5.2.4: Navegación Móvil y Enrutamiento Avanzado

Este subtema abarca:
- Navegación imperativa tradicional (`Navigator 1.0`).
- Enrutamiento declarativo con `GoRouter` (`Navigator 2.0`).
- Configuración de paramentros en rutas, query params y sub-rutas.
- Navegación por pestañas (Tabs), cajón lateral (Drawer) y Guardas de Autenticación.
