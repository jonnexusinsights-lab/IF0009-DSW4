# Subtema 5.2.6: Pruebas Unitarias y Widget Testing en Aplicaciones Móviles

Este subtema abarca:
- Pruebas unitarias de lógica de negocio, BLoCs, Cubits y Servicios (`test` package).
- Pruebas de componentes de interfaz (*Widget Testing*) con `WidgetTester`, `pumpWidget()` y `find.byType`.
- Simulación y mocking de cliente HTTP RESTful con `mockito` o `mocktail`.
- Integración de reportes de cobertura de pruebas (*Code Coverage*) en desarrollo móvil.
