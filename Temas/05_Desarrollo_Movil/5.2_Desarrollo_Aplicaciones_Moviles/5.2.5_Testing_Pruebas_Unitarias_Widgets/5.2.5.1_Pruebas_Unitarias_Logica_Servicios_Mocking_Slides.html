La Pirámide de Pruebas de Software

  • Pruebas de Integración (E2E):
    • Flujos completos en dispositivo o emulador real. Lentas y costosas.
  • Pruebas de Widgets (Widget Testing):
    • Renderizado virtual de árboles de widgets y simulación de gestos.
  • Pruebas Unitarias (Unit Testing):
    • Base de la pirámide: prueban clases, métodos y DTOs aislados.
    • Ejecución ultra-rápida directamente en la Dart VM (milisegundos).

¿Por Qué Usar Mocking en Móvil?

  • Aislamiento Total: El test no debe depender de que el servidor Spring Boot esté encendido.
  • Determinismo: Respuestas idénticas e instantáneas cada vez que se ejecuta el comando flutter test.
  • Simulación de Casos Límite:
    • Respuestas 401 Unauthorized o 404 Not Found.
    • Timeouts y caídas abruptas de conexión (SocketException).
    • Payloads JSON con atributos corruptos o nulos.

Creación de Mocks con Mocktail

import 'package:flutter_test/flutter_test.dart';
import 'package:http/http.dart' as http;
import 'package:mocktail/mocktail.dart';

// Doble de prueba que simula el cliente HTTP
class MockHttpClient extends Mock implements http.Client {}

void main() {
  late MockHttpClient mockClient;
  late IncidenciaService service;

  setUp(() {
    mockClient = MockHttpClient();
    service = IncidenciaService(client: mockClient, baseUrl: 'http://api.test');
  });
}

Patrón GIVEN - WHEN - THEN en Dart

test('Debe retornar IncidenciaDTO cuando la API responde 200 OK', () async {
  // 1. GIVEN: Definición del comportamiento simulado
  when(() => mockClient.get(any(), headers: any(named: 'headers')))
      .thenAnswer((_) async => http.Response('{"id": 1, "titulo": "Fuga"}', 200));

  // 2. WHEN: Ejecución del método bajo prueba
  final resultado = await service.obtenerPorId(1);

  // 3. THEN: Comprobación de resultados esperados
  expect(resultado.id, equals(1));
  expect(resultado.titulo, equals('Fuga'));
  verify(() => mockClient.get(any(), headers: any(named: 'headers'))).called(1);
});

Validación de Excepciones y Errores

test('Debe lanzar Excepción cuando el servidor responde 404', () async {
  when(() => mockClient.get(any(), headers: any(named: 'headers')))
      .thenAnswer((_) async => http.Response('No encontrado', 404));

  expect(
    () async => await service.obtenerPorId(99),
    throwsA(isA<Exception>()),
  );
});
  • Valida que la aplicación capture adecuadamente las respuestas no exitosas.

Comandos de Ejecución

  • Ejecutar todas las pruebas del proyecto:
```bash flutter test ```
  • Ejecutar un archivo de prueba específico:
```bash flutter test test/unit/incidenciaservicetest.dart ```
  • Ejecutar pruebas con reporte detallado:
```bash flutter test --reporter expanded ```
