Widget Testing con WidgetTester, Finders y Métricas LCOV

Objetivos de la Sesión

  • Renderizar y evaluar componentes de UI con WidgetTester.
  • Dominar el ciclo de renderizado de prueba: pumpWidget, pump y pumpAndSettle.
  • Localizar elementos en el árbol con find.text, find.byKey y find.byType.
  • Simular interacciones de usuario: toques (tap) e ingreso de texto (enterText).
  • Generar y analizar reportes de cobertura de código (LCOV) en Flutter.

Naturaleza del Widget Testing

  • Sin Emulador Gráfico: Corre en un canvas virtual Headless en la máquina local.
  • Control Temporal Absoluto: El reloj del motor gráfico está pausado por defecto.
  • Orquestación de Frames:
    • tester.pumpWidget(widget): Monta el árbol de componentes.
    • tester.pump(duration): Avanza el reloj un frame discreto.
    • tester.pumpAndSettle(): Espera hasta que todas las animaciones concluyan.

Estrategias de Búsqueda con Finders

| Método Finder | Caso de Uso | Nivel de Robustez | |---|---|---| | find.byKey(Key('id')) | Identificador único desacoplado | Máxima (Recomendada) | | find.text('Guardar') | Textos específicos de UI | Moderada (frágil con i18n) | | find.byType(ElevatedButton) | Validación de presencia de clase | Genérica | | find.byIcon(Icons.camera) | Botones de hardware y acciones | Alta para multimedia |

Estructura de un Widget Test

testWidgets('Debe mostrar error si el campo está vacío', (WidgetTester tester) async {
  // 1. Montaje envuelto en MaterialApp (Obligatorio para temas y textos)
  await tester.pumpWidget(
    MaterialApp(home: Scaffold(body: IncidenciaFormWidget(onGuardar: (_, __) async {}))),
  );

  // 2. Simular pulsación del botón
  await tester.tap(find.byKey(const Key('boton_guardar')));

  // 3. Forzar el redibujado del frame
  await tester.pump();

  // 4. Aserción de presencia
  expect(find.text('El título es obligatorio'), findsOneWidget);
});

Simulación de Entrada de Usuario

testWidgets('Debe escribir y enviar datos correctamente', (WidgetTester tester) async {
  String? tituloIngresado;

  await tester.pumpWidget(
    MaterialApp(home: Scaffold(body: IncidenciaFormWidget(
      onGuardar: (t, _) async => tituloIngresado = t,
    ))),
  );

  // Escribir texto en el campo
  await tester.enterText(find.byKey(const Key('campo_titulo')), 'Poste Caído');
  await tester.tap(find.byKey(const Key('boton_guardar')));
  await tester.pumpAndSettle();

  expect(tituloIngresado, equals('Poste Caído'));
});

Medición de Cobertura de Código

  • Ejecución y Generación de LCOV:
```bash flutter test --coverage ``` Genera el archivo estandarizado coverage/lcov.info.
  • Generación de Reporte Visual HTML (con genhtml):
```bash genhtml coverage/lcov.info -o coverage/html ```
  • Permite identificar líneas sin ejecutar y ramas de error no cubiertas.

Trampas Comunes en Widget Testing

  • ❌ Olvidar envolver en MaterialApp: Lanza la excepción No Directionality widget found.
  • ❌ Usar pumpAndSettle() con spinners infinitos:
    • Si un CircularProgressIndicator gira indefinidamente, pumpAndSettle() colapsará por timeout.
    • Solución: Usar tester.pump(Duration(milliseconds: 500)).
  • ❌ Depender de coordenadas físicas fijas: Los toques deben enviarse a Finders, nunca a píxeles fijos que varían con la pantalla.
