Visual Studio Code vs. Android Studio y Stateful Hot Reload

Curso: IF0009 - Desarrollo de Software IV Profesor: Mag. Jonathan Granados C. Semestre: II-2026 | Universidad de Costa Rica

Objetivos de la Sesión

  • Comparar la arquitectura y consumo de memoria de VS Code y Android Studio.
  • Comprender la comunicación mediante Dart Language Server Protocol (LSP).
  • Analizar la mecánica interna de Stateful Hot Reload vs. Hot Restart.
  • Configurar parámetros de autoguardado e inspección en .vscode/settings.json.
  • Aplicar la convención obligatoria de Trailing Commas en Flutter.

Comparativa de Arquitectura: VS Code vs Android Studio

  • Visual Studio Code:
    • Basado en Electron (V8 / Node.js). Consumo liviano (350-700 MB RAM).
    • Conexión por LSP al Dart Analysis Server.
    • Ideal para desarrollo diario de UI, lógica Dart y navegación rápida.
  • Android Studio:
    • Basado en IntelliJ IDEA (JVM). Consumo exigente (1.8-3.5 GB RAM).
    • Suite completa con Gradle avanzado, Device File Explorer y NDK.
    • Indispensable para configurar módulos Android nativos y emuladores.

Stateful Hot Reload vs. Hot Restart

  • Stateful Hot Reload (r en terminal o Ctrl+S):
    • Inyecta nuevo código fuente directamente en la Dart VM.
    • Preserva el estado en memoria de los StatefulWidget.
    • No re-ejecuta initState() ni constructores estáticos.
  • Hot Restart (R o Ctrl+F5):
    • Reinicia el isolate de Dart por completo y llama a main().
    • Destruye el estado en memoria. Requerido tras alterar initState().

La Regla de Oro: Trailing Commas

// Mal formateado: dificulta lectura en equipos
return Scaffold(body: Center(child: Text('Hola')));

// Correcto: Con coma final despues de cada widget
return Scaffold(
  appBar: AppBar(
    title: const Text('Inicio'),
  ),
  body: const Center(
    child: Text('Hola Mundo'),
  ),
);
  • La coma final (),) le indica al formateador que separe los widgets en múltiples líneas indentadas.

Atajos de Teclado Esenciales

  • Alt + Enter (o Ctrl + .): Menú contextual de refactorización rápida (Wrap with Widget, Extract Widget).
  • F5: Iniciar sesión de depuración con breakpoints.
  • r: Disparar Stateful Hot Reload instantáneo.
  • R: Disparar Hot Restart completo.
  • Ctrl + Shift + P: Paleta de comandos (escriba Flutter: para acceder a utilidades).
