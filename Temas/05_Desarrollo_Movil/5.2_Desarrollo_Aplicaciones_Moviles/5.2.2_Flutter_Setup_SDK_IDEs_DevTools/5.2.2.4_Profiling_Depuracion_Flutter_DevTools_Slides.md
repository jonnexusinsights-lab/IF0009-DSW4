# Flutter Widget Inspector

* **Select Widget Mode:** Al tocar un elemento en pantalla, el IDE salta a su declaración de código.
* **Repaint Rainbow:** Dibuja bordes de colores aleatorios que cambian al repintar; ayuda a identificar redibujados innecesarios.
* **Show Guidelines:** Visualiza alineaciones, márgenes y cajas de colisión (*RenderBoxes*).
* **Details Tree:** Inspecciona propiedades inmutables y el objeto de renderizado subyacente.

---

# Performance Overlay y la Regla de los 16.6 ms

* Para mantener **60 FPS** fluidos, cada frame debe procesarse en menos de **16.6 ms**.
* **UI Thread (Gráfico Superior):**
  * Tiempo invertido por la CPU ejecutando código Dart y el árbol de widgets.
  * Barras rojas indican operaciones pesadas en el método `build()`.
* **Raster Thread (Gráfico Inferior):**
  * Tiempo invertido por la GPU dibujando píxeles y ejecutando shaders.
  * Barras rojas indican efectos gráficos caros (desenfoques excesivos).

# Memory Profiler y Prevención de Fugas

```dart
// Desechar controladores y streams en el dispose()
@override
void dispose() {
  // 1. Cancelar suscripciones para evitar listeners huerfanos
  _streamSubscription?.cancel();

  // 2. Liberar el controlador de texto de la memoria nativa
  _filtroController.dispose();

  super.dispose();
}
```

* Si no se cancelan listeners o controladores, el **Garbage Collector** no puede destruir el widget y la memoria RAM crece indefinidamente.

# Network Profiler: Auditoría RESTful

* **Monitoreo en Tiempo Real:** Inspecciona cada llamada HTTP/HTTPS realizada con `http` o `Dio`.
* **Métricas Clave:**
  * Método HTTP (GET, POST, PUT, DELETE).
  * Código de estado HTTP (200 OK, 401 Unauthorized, 500 Server Error).
  * Latencia en milisegundos y tamaño del payload JSON transferido.
  * Visualización de cabeceras de autorización (Tokens JWT Bearer).

---

# Regla de Oro del Profiling

* **Nunca realice profiling en Debug Mode:**
  * Las aserciones activas y la compilación JIT distorsionan las métricas de FPS y memoria.
* **Ejecute siempre en Profile Mode sobre hardware real:**

```powershell
# Compilacion AOT optimizada con telemetria activa
flutter run --profile
```

* Es la única forma de obtener mediciones térmicas y de rendimiento fidedignas.
