# ¿Qué es el Flutter SDK?

* **Toolchain de Compilación Cruzada:** No es solo una biblioteca; integra compiladores AOT y JIT.
* **Dart SDK Embebido:** Incluye un compilador Dart 3 pre-validado en `bin/cache/dart-sdk`.
* **Motor Gráfico Precompilado:** Descarga artefactos binarios de Impeller y Skia en caché.
* **Orquestador Universal:** Automatiza la compilación sobre Gradle (Android), Xcode (iOS) y CMake (Desktop).

# Estructura Interna del SDK

```
C:/src/flutter/
  ├── bin/
  │    ├── flutter.bat          <-- Script ejecutable para Windows
  │    └── cache/
  │         ├── artifacts/      <-- Motores binarios C++
  │         └── dart-sdk/       <-- SDK de Dart oficial
  └── packages/
       └── flutter/             <-- Código fuente del framework
```

* **Regla de oro:** No instale Dart por separado; utilice el provisto por Flutter.

# Configuración de Variables de Entorno

```powershell
# Agregar Flutter bin al PATH en Windows PowerShell
$FlutterPath = "C:\src\flutter\bin"
$CurrentPath = [Environment]::GetEnvironmentVariable("Path", "User")

if ($CurrentPath -notlike "*$FlutterPath*") {
    $NewPath = "$CurrentPath;$FlutterPath"
    [Environment]::SetEnvironmentVariable("Path", $NewPath, "User")
}
```

* Evite rutas con espacios (`C:\Program Files` genera fallas con Gradle).
* Utilice rutas deterministas como `C:\src\flutter`.

---

# Diagnóstico Completo con `flutter doctor`

```powershell
# Ejecutar analisis diagnostico con maxima verbosidad
flutter doctor -v
```

* **Canal Flutter:** Valida versión y hash de Git.
* **Android Toolchain:** Inspecciona SDK, JDK y licencias de Google.
* **Chrome / Web:** Verifica compatibilidad de depuración web.
* **Connected Devices:** Enumera emuladores y teléfonos físicos por ADB.

---

# Aceptación de Licencias de Android

```powershell
# Resolver advertencia: "Android license status unknown"
flutter doctor --android-licenses
```

* Requisito legal de Google para descargar dependencias nativas de Android.
* Presione `y` en cada contrato presentado en la consola interactiva.
* Requiere tener instalado el paquete `cmdline-tools` en Android Studio.

---

# Resumen de Mejores Prácticas

* Utilice exclusivamente el canal `stable` para proyectos del curso.
* Configure `JAVA_HOME` apuntando a OpenJDK 17 o al JBR de Android Studio.
* Cierre y reabra la consola PowerShell tras modificar variables de entorno.
* Mantenga actualizado el SDK ejecutando periódicamente `flutter upgrade`.
