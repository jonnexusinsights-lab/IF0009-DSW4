AVD Manager, Aceleración Gráfica y Protocolo ADB

Objetivos de la Sesión

  • Comprender la arquitectura de virtualización del emulador Android (QEMU/WHPX).
  • Configurar la aceleración gráfica por hardware (Hardware - GLES 2.0).
  • Dominar el protocolo ADB (Android Debug Bridge) y sus comandos clave.
  • Habilitar la Depuración por USB con autenticación criptográfica RSA.
  • Operar la Depuración Inalámbrica (Wireless Debugging) en redes locales.

Arquitectura de Emulación: QEMU y Aceleración

  • Motor Base: El emulador de Android corre sobre una instancia de QEMU.
  • Virtualización x86_64: En PCs con Intel/AMD, el código de Android corre a velocidad nativa sin traducción binaria.
  • Aceleradores de Hipervisor:
    • Windows: Windows Hypervisor Platform (WHPX) o Android Emulator Hypervisor Driver (AEHD).
    • macOS: Hypervisor.framework.
    • Linux: KVM (Kernel-based Virtual Machine).
  • Gráficos por GPU: Seleccione siempre Hardware - GLES 2.0 para que la tarjeta gráfica física dibuje los frames.

Comandos de Consola: ADB y Flutter CLI

# 1. Ver dispositivos fisicos y virtuales conectados
adb devices -l

# 2. Listar emuladores AVD instalados en el sistema
flutter emulators

# 3. Iniciar un emulador desde la terminal
flutter emulators --launch Pixel_8_API_34

# 4. Lanzar la aplicacion en un target especifico
flutter run -d emulator-5554
  • El flag -d permite elegir dinámicamente entre Chrome, emuladores y teléfonos reales.

Configuración de Dispositivos Físicos (USB)

  • Paso 1: En el teléfono Android, ingrese a Ajustes > Acerca del Teléfono.
  • Paso 2: Presione 7 veces seguidas el Número de Compilación para activar el modo de desarrollador.
  • Paso 3: En Opciones de Desarrollador, active Depuración por USB.
  • Paso 4: Conecte el cable USB y confirme el diálogo de seguridad RSA marcando "Permitir siempre desde esta computadora".
  • Beneficio: Rendimiento real a 60/120 FPS sin consumir memoria RAM del computador de desarrollo.

Depuración Inalámbrica (Wireless Debugging)

# 1. Emparejar con codigo de 6 digitos (Android 11+)
adb pair 192.168.1.15:42135

# 2. Conectar al socket final de depuracion
adb connect 192.168.1.15:39841

# 3. Verificar enlace activo en ADB
adb devices
  • Requiere que el teléfono y la computadora compartan la misma red WiFi.
  • Elimina la dependencia de cables físicos para pruebas de movilidad.
