# Subtema 5.2.5: Consumo de APIs RESTful (Spring Boot / JWT), Persistencia Local y Hardware

Este subtema abarca:
- Consumo asíncrono de APIs RESTful en Spring Boot (`http` package, DTOs, manejo de errores).
- Almacenamiento seguro de Tokens JWT con `FlutterSecureStorage` (Keystore / Keychain).
- Persistencia local relacional con `sqflite` (SQLite) y clave-valor con `SharedPreferences`.
- Patrón de arquitectura **Offline-First**: sincronización local/remota de datos.
- Acceso e integración con hardware nativo del dispositivo (GPS / Geolocalización, Cámara, Galería).
- Manejo de permisos nativos en Android (`AndroidManifest.xml`) e iOS (`Info.plist`).
