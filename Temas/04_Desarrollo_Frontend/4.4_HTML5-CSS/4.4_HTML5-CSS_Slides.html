HTML5 Semántico y el DOM Tree

HTML5 estructura el significado del contenido y construye en memoria el Árbol del DOM (Document Object Model Tree).
  • Etiquetas Semánticas de Estructura:
    • <header>: Encabezado del documento o sección.
    • <nav>: Bloque de navegación principal.
    • <main>: Contenido principal e incremental (1 por página).
    • <section>: Agrupación temática con encabezado.
    • <article>: Composición autónoma re-distribuible.
    • <aside>: Barra lateral o contenido tangencial.
    • <footer>: Pie de página o cierre legal/contacto.

El Modelo de Caja CSS (Box Model)

Cada elemento HTML se renderiza como una caja concéntrica de 4 capas: Content, Padding, Border y Margin. 
/* Regla Universal Obligatoria */
*, *::before, *::after {
    box-sizing: border-box;
}
  • Sin border-box (content-box):
    • Ancho Final = width + padding + border (Provoca desbordamientos).
  • Con border-box:
    • width incluye el padding y el border de forma elástica.

Especificidad CSS (a, b, c, d)

Determina la prioridad de los estilos cuando múltiples selectores coinciden.
  • a (1000): Estilos inline (style="...").
  • b (100): Selectores de ID (#txtNombre).
  • c (10): Clases (.btn), Atributos ([type="email"]) y Pseudo-clases (:hover).
  • d (1): Elementos HTML (h1, div) y Pseudo-elementos (::before).
$$\text{Especificidad} = (a \cdot 1000) + (b \cdot 100) + (c \cdot 10) + d$$

CSS Flexbox (Diagramación Unidimensional)

Ideal para organizar elementos en un único eje (Fila o Columna). 
.flex-container {
    display: flex;
    flex-direction: row; /* Eje Principal: Horizontal */
    justify-content: space-between; /* Alineacion Eje Principal */
    align-items: center; /* Alineacion Eje Cruzado */
    flex-wrap: wrap; /* Permitir salto de linea */
}
  • Propiedades Clave:
    • justify-content: flex-start, center, space-between.
    • align-items: stretch, center, flex-end.

CSS Grid Layout (Diagramación Bidimensional)

Maquetación fluida en Filas y Columnas simultáneas. 
.grid-container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 1.5rem;
}
  • repeat(auto-fit, minmax(250px, 1fr)):
    • Crea una retícula elástica autoadaptable.
    • Mantiene las columnas en un tamaño mínimo de 250px.
    • Rena y distribuye proporcionalmente (1fr) el espacio sobrante.

Variables CSS y Enfoque Mobile-First

    --primary: #38bdf8;
    --bg-dark: #0f172a;
}

.layout {
    display: flex;
    flex-direction: column;
}

/* 2. Media Query Adaptativa para Escritorio */
@media (min-width: 768px) {
    .layout {
        display: grid;
        grid-template-columns: 240px 1fr;
    }
}
