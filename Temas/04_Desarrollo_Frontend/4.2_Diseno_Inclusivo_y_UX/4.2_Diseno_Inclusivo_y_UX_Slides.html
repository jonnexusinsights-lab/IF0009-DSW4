UI vs UX: Estética vs Experiencia

  • Interfaz de Usuario (UI - User Interface):
    • Componentes gráficos, tipografía, paleta de colores, controles y estética visual.
  • Experiencia de Usuario (UX - User Experience):
    • Respuesta emocional, grado de eficiencia y satisfacción integral al interactuar con el sistema.
  • Los 5 Pilares de Usabilidad de Nielsen (U8y):
    1. Facilidad de Aprendizaje (Learnability).
    2. Eficiencia de Uso (Efficiency).
    3. Facilidad de Memorización (Memorability).
    4. Tolerancia a Errores (Errors).
    5. Satisfacción de Uso (Satisfaction).

Internacionalización (i18n) y Localización (l10n)

  • Internacionalización (i18n):
    • Diseño arquitectónico desacoplado para soportar múltiples lenguajes y regiones sin alterar el código fuente base.
  • Localización (l10n):
    • Adaptación regional de textos, formatos de fecha, moneda, zona horaria y números (Intl.DateTimeFormat).
  • Regla de Oro HTML:
    • Actualizar el atributo de idioma global <html lang="es"> / <html lang="en"> para guiar a los motores de síntesis de voz.

Accesibilidad Web (A11y) y Estándar WCAG 2.1

Garantiza que la web sea utilizable por personas con diversas capacidades sensoriales, motoras o cognitivas. Principios WCAG 2.1 (POUR):
  • P - Perceptible: Texto alternativo (alt), subtítulos y contraste de color mínimo de 4.5:1 (Nivel AA).
  • O - Operable: Navegación 100% mediante teclado (Tab, Enter, Space) e indicadores de foco visibles.
  • U - Comprensible: Formularios predecibles e indicación clara de errores.
  • R - Robusto: Compatibilidad con lectores de pantalla vía WAI-ARIA (aria-label, aria-live, role).

Antipatrones Comunes de Accesibilidad

  • Eliminar el Anillo de Foco (outline: none):
    • Deja sin guía visual a los usuarios que navegan exclusivamente mediante la tecla Tab.
  • Depender Únicamente del Color para Indicar Estado:
    • Usar solo colores (rojo/verde) sin texto ni íconos discrimina a personas con daltonismo.
  • Botones e Íconos Sin Texto Alternativo:
    • Botones SVG sin aria-label resultan completamente invisibles para los lectores de pantalla.
