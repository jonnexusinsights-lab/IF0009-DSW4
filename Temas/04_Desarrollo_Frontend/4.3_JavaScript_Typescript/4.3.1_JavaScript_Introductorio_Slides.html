¿Qué es JavaScript (EcmaScript)?

Lenguaje estándar de programación interpretado, multiparadigma, de tipado dinámico y ejecutable en el navegador.
  • Declaración de Variables en ES6+:
    • const: Referencia inmutable de ámbito de bloque. Opción por defecto (90% de los casos).
    • let: Variable mutable reasignable restringida al bloque { ... }.
    • var: Obsoleto. Posee ámbito de función (function scope) y sufre de elevación (hoisting).

Tipos de Datos y Operadores Estrictos

  • Tipos Primitivos (Inmutables por Valor):
    • string, number, boolean, null, undefined, symbol, bigint.
  • Tipos de Referencia (Mutables en Memoria):
    • Object, Array, Function, Date.
  • Regla de Oro de Comparación:
    • Use siempre el operador de igualdad estricta === y !== (compara valor y tipo).
    • Evite == por problemas de conversión implícita de tipos (Type Coercion).

Funciones Tradicionales vs Arrow Functions (=>)

Sintaxis concisa que elimina la vinculación dinámica de this (adopta this léxico): 
// Función Tradicional
function calcularTotal(precio, impuesto) {
    return precio + (precio * impuesto);
}

// Arrow Function equivalente (retorno implícito en una línea)
const calcularTotalArrow = (precio, impuesto) => precio * (1 + impuesto);

Manipulación Básica del DOM y Eventos

document.addEventListener('DOMContentLoaded', () => {
    const btn = document.getElementById('btnProcesar');
    const contenedor = document.getElementById('salida');

    const listaPaquetes = ['ENV-101', 'ENV-102'];

    btn.addEventListener('click', () => {
        contenedor.innerHTML = '';
        listaPaquetes.forEach((codigo, idx) => {
            const p = document.createElement('p');
            p.textContent = `[#${idx + 1}] Paquete: ${codigo}`;
            contenedor.appendChild(p);
        });
    });
});

Antipatrones Comunes

  • Confundir Inmutabilidad de Referencia con Inmutabilidad de Objetos:
    • const arr = []; impide arr = [1], pero permite arr.push(1).
  • Uso de var y Fuga de Variables al Ámbito Global:
    • Genera colisiones no deseadas en el objeto window.
  • Uso de == en Lugar de ===:
    • Produce resultados inesperados como 0 == '' evaluando a true.
