# Tema 4.3.1: Fundamentos de JavaScript Moderno (Introducción a EcmaScript)

## Resumen

Este tema aborda los conceptos esenciales de **JavaScript (EcmaScript)** como el lenguaje de programación estándar del lado del cliente. Se analiza la sintaxis moderna introducida en ES6+, el sistema de tipos dinámicos, la declaración adecuada de variables (`const`, `let` frente al obsoleto `var`), las estructuras de datos fundamentales (arreglos y objetos), las funciones tradicionales frente a las funciones de flecha (*Arrow Functions*), y la manipulación elemental del Árbol del Modelo de Objetos del Documento (*DOM*) mediante eventos del navegador.

---

## Concepto Principal (El 'Qué')

**JavaScript** es un lenguaje de programación interpretado, de alto nivel, de tipado dinámico, multiparadigma (orientado a objetos, funcional e imperativo) y de un solo hilo de ejecución (*single-threaded*). Es estandarizado bajo la especificación **ECMA-262 (EcmaScript)**.

### 1. Declaración de Variables: `const`, `let` y `var`

La especificación ES6 (2015) revolucionó el manejo de memoria introduciendo el ámbito de bloque (*block scope*):

* **`const` (Constante de Ámbito de Bloque):** Declara una referencia inmutable. No permite reasignación de variable (`const x = 10; x = 20; // Error`). Nota: Si el valor es un objeto o arreglo, sus propiedades internas sí pueden mutar. Debe ser la opción por defecto en el 90% del código.
* **`let` (Variable de Ámbito de Bloque):** Declara una variable mutable reasignable cuyos límites de acceso están restringidos estrictamente al bloque `{ ... }` donde fue definida.
* **`var` (Legado de Ámbito de Función - ¡Obsoleto!):** Posee ámbito de función (*function scope*) y sufre de elevación (*hoisting*), declarando variables globales accidentales en `window`. **No debe utilizarse en código moderno.**

### 2. Tipos de Datos y Sistema de Tipado

JavaScript divide sus valores en dos grandes categorías:

1. **Tipos Primitivos (Inmutables por Valor):** `string`, `number`, `boolean`, `null`, `undefined`, `symbol`, `bigint`.
2. **Tipos de Referencia (Mutables por Dirección de Memoria):** `Object`, `Array`, `Function`, `Date`.

### 3. Funciones Tradicionales vs Arrow Functions (`=>`)

Las **Arrow Functions** proporcionan una sintaxis concisa y eliminan la vinculación propia de la palabra clave `this` (heredan el `this` léxico del contexto superior):

```javascript
// Función Tradicional
function sumar(a, b) {
    return a + b;
}

// Arrow Function equivalente (Retorno implícito)
const sumarArrow = (a, b) => a + b;
```

---

## Analogía (La Intuición)

Imagine un cuaderno de notas de oficina:

* **Variable `const` (Tinta Indeleble en una Caja Fuerte):** Usted escribe el nombre del dueño en la portada con tinta indeleble y guarda el cuaderno en una caja fuerte sellada. La etiqueta del cuaderno nunca puede cambiarse por otra (`const`). Sin embargo, el dueño puede abrir el cuaderno y escribir nuevas hojas por dentro (mutabilidad de propiedades en arreglos/objetos `const`).
* **Variable `let` (Lápiz con Borrador):** Es una hoja en sucio escrita con lápiz. Usted puede borrar el número anotado y escribir uno nuevo sobre el mismo espacio cuantas veces requiera (`let`).
* **Variable `var` (Un Megáfono en el Pasillo Central):** Gritar un mensaje por un megáfono en el pasillo principal. Todo el edificio escucha la variable sin importar en qué oficina cerrada (`bloque`) se encuentre usted, causando confusiones y colisiones de nombres con otros departamentos.

## Ejemplo de Código e Implementación (El 'Cómo')

A continuación se muestra un script moderno en JavaScript (ES6+) que demuestra la declaración limpia de variables, arreglos y eventos del DOM:

```javascript
// 1. Declaración limpia de constantes e inmutabilidad de referencias
const CONFIGURACION = {
    version: '1.0.0',
    entorno: 'desarrollo'
};

// 2. Manipulación de arreglos básicos
const listaPaquetes = ['ENV-101', 'ENV-102', 'ENV-103'];
listaPaquetes.push('ENV-104'); // Válido en arreglos const

// 3. Arrow function para procesamiento de datos
const formatearPaquete = (codigo, indice) => {
    return `[#${indice + 1}] Código Oficial: ${codigo.toLowerCase()}`;
};

// 4. Manipulación del DOM y registro de eventos
document.addEventListener('DOMContentLoaded', () => {
    const contenedor = document.getElementById('app');
    let contadorClick = 0; // Variable mutable controlada

    const boton = document.createElement('button');
    boton.textContent = 'Procesar Envíos';
    
    boton.addEventListener('click', () => {
        contadorClick++;
        contenedor.innerHTML = ''; // Limpiar contenedor
        
        listaPaquetes.forEach((codigo, idx) => {
            const p = document.createElement('p');
            p.textContent = formatearPaquete(codigo, idx);
            contenedor.appendChild(p);
        });

        console.log(`Procesamiento #${contadorClick} completado.`);
    });

    contenedor.appendChild(boton);
});
```

### Explicación Paso a Paso del Código:

1. **`const CONFIGURACION`**: Protege la referencia del objeto global.
2. **`listaPaquetes.push(...)`**: Demuestra que los métodos modificadores de arreglos funcionan sobre variables `const` sin alterar la referencia en memoria.
3. **`formatearPaquete`**: Implementa una *Arrow Function* con retorno implícito utilizando *Template Literals* (cadenas interpoladas con backticks `` `${...}` ``).
4. **Manipulación del DOM**: Agrega escuchadores de eventos mediante `addEventListener('click', ...)` y crea nodos HTML de forma dinámica de forma limpia.

## Trampas Comunes

*   **Confundir la Inmutabilidad de Referencia con la Inmutabilidad de Contenido:**
    *   *Error:* Pensar que `const arreglo = [1, 2];` impide ejecutar `arreglo.push(3);`.
    *   *Solución:* Entender que `const` evita reasignar la variable (`arreglo = []`), pero no congela el objeto subyacente. Para congelar el objeto use `Object.freeze()`.

*   **Comparación Débil con `==` en lugar de Comparación Estricta con `===`:**
    *   *Error:* Utilizar `0 == '0'` (retorna `true` por conversión implícita de tipos o *Type Coercion*).
    *   *Solución:* Utilizar siempre el operador de igualdad estricta `===` (que compara valor y tipo de dato) y `!==`.

*   **Pérdida del Contexto de `this` en Funciones de Callback Tradicionales:**
    *   *Error:* Usar `function()` en manejadores de eventos o temporizadores `setTimeout` esperando acceder a las propiedades de la clase contenedora.
    *   *Solución:* Emplear *Arrow Functions* (`=>`) que preservan automáticamente el ámbito léxico de `this`.
