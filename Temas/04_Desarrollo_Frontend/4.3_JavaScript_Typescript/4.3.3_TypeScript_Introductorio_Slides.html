¿Qué es TypeScript?

Superconjunto tipado (superset) de JavaScript desarrollado por Microsoft que se transpila a JavaScript puro ejecutable en cualquier navegador. $$\text{TypeScript} = \text{JavaScript} + \text{Tipado Estático} + \text{Herramientas Compilación}$$
  • El Compilador tsc y tsconfig.json:
    • Define las reglas de transpilación y rigor ("strict": true).
    • Las comprobaciones ocurren en tiempo de compilación (prevención de bugs previa a producción).

Tipos Primitivos y Tipos Especiales

  • Primitivos: string, number, boolean.
  • Arreglos y Tuplas: let lista: string[], let tupla: [number, string].
  • any (Escape Hatch - ¡Evitar!): Desactiva la verificación de tipos.
  • unknown (Tipo Seguro Desconocido): Alternativa segura a any. Exige Type Guards antes de operarse.
  • void y never: Ausencia de retorno vs funciones que lanzan excepciones o no terminan.

Contratos de Datos: interface vs type

  • interface: Estructura extensible y orientada a objetos. Estándar para modelos DTO en Angular.
  • type (Type Alias): Para uniones de tipos, tuplas y tipos complejos.

export interface Envio {

Funciones Tipadas y Cálculo Seguro

// Función fuertemente tipada con retorno explícito
export const calcularFlete = (
    pesoKg: number, 
    tarifaPorKg: number = 1500
): number => {
    if (pesoKg <= 0) {
        throw new Error("El peso debe ser mayor a cero.");
    }
    return pesoKg * tarifaPorKg;
};

export const procesarEnvio = (envio: Envio): string => {
    const costo = calcularFlete(envio.pesoKg);
    return `Envío #${envio.id} [${envio.estado}] - Costo: ₡${costo}`;
};

Antipatrones Comunes

  • Uso Abusivo de any (Any-script):
    • Elimina los beneficios del compilador. Use unknown o interfaces explícitas.
  • Asumir que las Interfaces Existen en Runtime:
    • Las interfaces se eliminan por completo (Type Erasure) al transpilar a JavaScript.
  • Ignorar el Indicador de Strictness ("strict": false):
    • Permite nulos implícitos provocando errores en ejecución.
