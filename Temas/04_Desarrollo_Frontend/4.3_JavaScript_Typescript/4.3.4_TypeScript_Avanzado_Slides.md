# Genéricos en TypeScript (`<T>`)

Permiten crear estructuras y componentes reutilizables sin perder el rigor del tipado estático:

```typescript
// Interface Genérica para Respuestas de APIs Paginadas
export interface RespuestaPaginada<T> {
    contenido: T[];
    totalElementos: number;
    paginaActual: number;
}
```

* **Restricciones (`extends`):**
  * Limitan los tipos pasados al parámetro genérico: `<T extends { id: number }>`.

# Type Narrowing y Type Guards

* **Estrechamiento de Tipos (*Type Narrowing*):**
  * Permite operar de forma segura con Tipos de Unión (`string | number`).
* **Operadores Nativo y Predicados de Tipo (`is`):**

```typescript
// Predicado de Tipo (Type Guard Personalizado)
export function esVehiculo(objeto: any): objeto is VehiculoDto {
    return objeto && typeof objeto.placa === 'string';
}
```

# Tipos de Utilidad (*Utility Types*)

Manipulación y transformación de tipos existentes sin duplicación de código:

* **`Partial<T>`:** Convierte todas las propiedades en opcionales (`?`). Ideal para `PATCH`.
* **`Required<T>`:** Hace obligatorias todas las propiedades.
* **`Readonly<T>`:** Inmutabilidad total de propiedades.
* **`Pick<T, K>`:** Selecciona un subconjunto de claves `K`.
* **`Omit<T, K>`:** Omite un subconjunto de claves `K`. Ideal para DTOs de creación sin `id`.
* **`Record<K, T>`:** Diccionarios / mapas tipados.

# Servicio Genérico REST con Utility Types

```typescript
export type CrearVehiculoDto = Omit<VehiculoDto, 'id'>;
export type ActualizarVehiculoDto = Partial<CrearVehiculoDto>;

export class ClienteRestGenerico<T extends { id: number }> {
    constructor(private endpointBase: string) {}

    async buscarPorId(id: number): Promise<T> {
        const res = await fetch(`${this.endpointBase}/${id}`);
        return await res.json();
    }

    async actualizarParcial(id: number, cambios: Partial<T>): Promise<T> {
        const res = await fetch(`${this.endpointBase}/${id}`, {
            method: 'PATCH',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify(cambios)
        });
        return await res.json();
    }
}
```

# Antipatrones Avanzados

* **Aserciones Forzadas (`as Type`):**
  * Forzar tipos sin validaciones runtime oculta bugs silenciosos.
* **Abuso de Genéricos Innecesarios:**
  * Crear múltiples parámetros `<T, U, V>` cuando interfaces simples resuelven el caso.
* **Confundir `Omit` con `Pick`:**
  * Usar `Omit` para seleccionar 2 campos de una estructura con 20 propiedades.
