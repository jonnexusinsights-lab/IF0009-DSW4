Programación Funcional en Arreglos

Reemplazo de bucles for tradicionales por operaciones inmutables de orden superior:
  • map(fn): Transforma elementos y retorna un nuevo arreglo de igual longitud.
  • filter(fn): Retorna un nuevo arreglo con los elementos que cumplen un predicado booleano.
  • reduce(fn, init): Acumula y reduce la colección a un único valor resultante.
  • find(fn) / some(fn) / every(fn): Métodos de búsqueda e inspección lógica rápida.

Arquitectura del Event Loop de V8

Mecanismo monohilo (single-threaded) no bloqueante para procesamiento asíncrono:
  1. Call Stack: Pila de invocación de funciones síncronas.
  2. Web APIs: Delegación externa de tareas lentas (fetch, setTimeout).
  3. Microtask Queue (Promesas): Pila de alta prioridad resuelta en async/await.
  4. Macrotask Queue: Callbacks ordinarios de temporizadores.

Promesas Concurrente y OOP en ES6+

export class ServicioEnvios {
    #apiKey; // Campo privado de clase (ES2022)

    constructor(apiKey) { this.#apiKey = apiKey; }

    async obtenerEnviosParalelos(listaIds) {
        // Ejecución concurrente en paralelo con Promise.all
        const promesas = listaIds.map(id => 
            fetch(`/api/v1/envios/${id}`, {
                headers: { 'Authorization': `Bearer ${this.#apiKey}` }
            }).then(res => res.json())
        );
        return await Promise.all(promesas);
    }
}

Operadores de Encadenamiento Opcional y Respaldo

  • Optional Chaining (?.): Evita errores TypeError: Cannot read properties of undefined.
  • Nullish Coalescing (??): Asigna valores por defecto sólo ante null o undefined. 
// Seguridad al acceder a estructuras anidadas
const clienteNombre = envio?.cliente?.nombre ?? 'Cliente Anónimo';

Antipatrones Avanzados

  • await en Bucles for...of Secuenciales:
    • Suma latencias en serie. Use Promise.all() con map().
  • Mutación Accidental de Arreglos Originales:
    • El uso de sort() o splice() modifica el arreglo original. Use [...arr].sort() o toSorted().
  • Olvidar Retornar Valores en map() / reduce():
    • Produce arreglos con valores undefined.
