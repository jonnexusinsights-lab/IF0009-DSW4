# Arquitectura Standalone en Angular 19

Angular ha sustituido los tradicionales `NgModule` por **Componentes Standalone**.

```typescript
import { Component } from '@angular/core';
import { CommonModule } from '@angular/common';

@Component({
  selector: 'app-mi-componente',
  standalone: true,
  imports: [CommonModule],
  template: `<h1>Componente Independiente</h1>`
})
export class MiComponente {}
```

* **Ventajas Principales:**
  * Desacoplamiento total del árbol de componentes.
  * Carga diferida (*Lazy Loading*) directa de componentes por ruta.
  * Menor fricción de aprendizaje y proyectos más ligeros.

# El Nuevo Paradigma: Angular Signals

Mecanismo de reactividad granular que notifica al DOM qué nodos específicos actualizar sin re-evaluar todo el árbol de componentes (*Zone.js*).

```typescript
import { Component, signal, computed } from '@angular/core';

@Component({
  selector: 'app-demo-signal',
  standalone: true,
  template: `<p>Total: {{ total() }}</p>`
})
export class DemoSignalComponent {
  // 1. Writable Signal
  precio = signal<number>(100);
  cantidad = signal<number>(2);

  // 2. Computed Signal (Estado Derivado de Solo Lectura)
  total = computed(() => this.precio() * this.cantidad());
}
```

# Control de Flujo Moderno en Plantillas

Angular 17+ reemplazó `*ngIf` y `*ngFor` por bloques nativos compilados:

```html

@if (cargando()) {
    <p>Cargando datos...</p>

    <!-- Iteracion @for con tracking obligatorio -->
```

# Interceptores HTTP y Route Guards Funcionales

* **Interceptor HTTP Funcional (`HttpInterceptorFn`):**
  * Adjunta automáticamente el token JWT (`Authorization: Bearer`).

* **Route Guard Funcional (`CanActivateFn`):**
  * Protege rutas revisando si el usuario está autenticado.

```typescript
export const authGuard: CanActivateFn = (route, state) => {
  const authService = inject(AuthService);
  const router = inject(Router);
  return authService.estaAutenticado() ? true : router.parseUrl('/login');
};
```

# Live Coding - Paso 3: Servicio Auth con Signals

```typescript
import { Injectable, signal, computed } from '@angular/core';

@Injectable({ providedIn: 'root' })
export class AuthService {
  private tokenSignal = signal<string | null>(
    localStorage.getItem('jwt_token')
  );

  estaAutenticado = computed(() => this.tokenSignal() !== null);

  obtenerToken(): string | null {
    return this.tokenSignal();
  }

  guardarToken(token: string): void {
    localStorage.setItem('jwt_token', token);
    this.tokenSignal.set(token);
  }
}
```

# Live Coding - Paso 4: Interceptor JWT Funcional

```typescript
import { HttpInterceptorFn } from '@angular/common/http';
import { inject } from '@angular/core';
import { AuthService } from '../services/auth.service';

export const jwtInterceptor: HttpInterceptorFn = (req, next) => {
  const authService = inject(AuthService);
  const token = authService.obtenerToken();

  if (token) {
    const reqClonada = req.clone({
      setHeaders: { Authorization: `Bearer ${token}` }
    });
    return next(reqClonada);
  }

  return next(req);
};
```

# Live Coding - Paso 5: Guard de Ruta Funcional

```typescript
import { CanActivateFn, Router } from '@angular/router';
import { inject } from '@angular/core';
import { AuthService } from '../services/auth.service';

export const authGuard: CanActivateFn = (route, state) => {
  const authService = inject(AuthService);
  const router = inject(Router);

  if (authService.estaAutenticado()) {
    return true;
  }

  router.navigate(['/login']);
  return false;
};
```

# Live Coding - Paso 6: Servicio Paquete REST

```typescript
import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';
import { Paquete } from '../domain/paquete.model';

@Injectable({ providedIn: 'root' })
export class PaqueteService {
  private readonly http = inject(HttpClient);
  private readonly apiUrl = 'http://localhost:8080/api/v1/paquetes';

  obtenerPaquetes(): Observable<Paquete[]> {
    return this.http.get<Paquete[]>(this.apiUrl);
  }
}
```

# Live Coding - Paso 7: Componente Standalone con Signals

```typescript
import { Component, inject, OnInit, signal } from '@angular/core';
import { CommonModule } from '@angular/common';
import { PaqueteService } from '../services/paquete.service';
import { Paquete } from '../domain/paquete.model';

@Component({
  selector: 'app-paquete-list',
  standalone: true,
  imports: [CommonModule],
  templateUrl: './paquete-list.component.html'
})
export class PaqueteListComponent implements OnInit {
  private paqueteService = inject(PaqueteService);

  paquetes = signal<Paquete[]>([]);
  cargando = signal<boolean>(true);

  ngOnInit(): void {
    this.paqueteService.obtenerPaquetes().subscribe(data => {
      this.paquetes.set(data);
      this.cargando.set(false);
    });
  }
}
```
