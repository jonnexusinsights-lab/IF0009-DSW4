# ¿Qué es el Desarrollo Front-End?

La capa de presentación, interfaz visual y lógica de interacción ejecutada en el **agente de usuario** (navegador web o app cliente).

* **La Tríada de Estándares Web:**
  * **HTML (Estructura y Semántica):** Árbol del DOM.
  * **CSS (Presentación y Estética):** Estilos, Flexbox/Grid y responsividad.
  * **JavaScript / TypeScript (Comportamiento):** Manipulación del DOM, asincronía y estado dinámico.

# Evolución de las Arquitecturas Web

* **Web Tradicional (Server-Side Rendering - SSR):**
  * Servidor procesa cada página HTML completa.
  * Requiere recarga total de la pantalla (*Full Page Reload*).
* **Web Moderna (Single-Page Application - SPA / CSR):**
  * El navegador descarga el cascarón base e hidrata la vista.
  * Consume datos dinámicos mediante APIs RESTful en JSON.
  * Elimina el parpadeo de pantalla y mejora la experiencia de usuario.

# Responsabilidades de Ingeniería Front-End

1. **Arquitectura y Gestión de Estado Cliente:**
   * Diseño de componentes reutilizables y flujos de datos unidireccionales/reactivos.
2. **Rendimiento Web (Core Web Vitals):**
   * Optimización de métricas (LCP, CLS, INP), *code-splitting* y *tree-shaking*.
3. **Integración Asíncrona y Seguridad:**
   * Consumo de APIs REST (HTTPS/JWT), sanitización contra **XSS** e higiene de almacenamiento.
4. **Diseño Responsivo e Inclusividad:**
   * Estrategia *Mobile-First* y cumplimiento de estándares de accesibilidad (WCAG 2.1 AA).

# Consumo Asíncrono y Prevención de XSS

```javascript
// JS Modular con Async/Await y Sanitización Segura del DOM
btnCargar.addEventListener('click', async () => {
    try {
        const response = await fetch('/api/v1/envios');
        const data = await response.json();
        renderizar(data);
    } catch (err) {
        status.textContent = `Error: ${err.message}`;
    }
});

function renderizar(items) {
    lista.innerHTML = '';
    items.forEach(item => {
        const li = document.createElement('li');
        li.textContent = item.nombre; // Prevención XSS usando textContent
        lista.appendChild(li);
    });
}
```

# Antipatrones Comunes en Front-End

* **Fat Components (Lógica de vista sobrecargada):**
  * Meclado de llamadas HTTP y cálculos de negocio dentro del renderizado visual.
* **Uso de `innerHTML` con Datos No Confiables:**
  * Concatenar cadenas HTML directamente abre vulnerabilidades críticas de XSS.
* **Bloqueo del Hilo Principal (*Main Thread Freezing*):**
  * Bucles masivos asíncronos no optimizados que congelan la interfaz del usuario.
