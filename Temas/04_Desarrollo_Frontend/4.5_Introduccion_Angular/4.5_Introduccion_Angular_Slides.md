# ¿Qué es Angular?

Framework de desarrollo web empresarial multiplataforma diseñado para la construcción de **Single-Page Applications (SPA)** escalables.

* **Características Clave:**
  * Desarrollado en **TypeScript** (superconjunto tipado de JavaScript).
  * Arquitectura orientada a **Componentes**, **Servicios**, **Pipes** y **Directivas**.
  * Soporte multiplataforma: Aplicaciones Web, Móviles y de Escritorio.
  * Inyección de dependencias nativa y control de estado reactivo.

# ¿Por qué usar un Framework Front-End?

* **Múltiples Factores de Forma:** Adaptabilidad visual dinámica para diversos tamaños de pantalla y dispositivos.
* **Rich UI & UX:** Interfaces interactivas de alto rendimiento sin recarga completa de página (*No Full Page Reload*).
* **Single-Page Application (SPA):**
  * Renderizado dinámico de contenido cliente.
  * Preservación del contexto del usuario y comunicación asíncrona mediante JSON.

# Configuración del Ambiente de Trabajo

1. **Node.js & NPM:**
   * Entorno de ejecución JavaScript e instalador de paquetes.
   * Verificar versión: `node --version` (Recomendado v20+ / v22+).

2. **Angular CLI (`@angular/cli`):**
   ```bash
   npm install -g @angular/cli
   ```
   * Comandos principales:
     * `ng new mi-app`: Crea un nuevo proyecto Angular.
     * `ng serve`: Inicia el servidor de desarrollo (`http://localhost:4200`).
     * `ng generate service actor`: Genera un nuevo servicio inyectable.

# Arquitectura de Componentes en Angular

Un **Componente** encapsula la estructura visual (HTML), la lógica de negocio (TS) y la maquetación visual (CSS).

```typescript
import { Component } from '@angular/core';

@Component({
  selector: 'app-saludo',
  standalone: true,
  template: `<h1>{{ titulo }}</h1>`,
  styles: [`h1 { color: #38bdf8; }`]
})
export class SaludoComponent {
  titulo: string = 'Bienvenido a Angular 19';
}
```

# Servicios Inyectables e HttpClient

Los **Servicios** contienen la lógica de negocio desacoplada de la vista y la integración con APIs RESTful.

```typescript
import { Injectable, inject } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';
import { Actor } from '../domain/actor.model';

@Injectable({
  providedIn: 'root'
})
export class ActorService {
  private readonly http = inject(HttpClient);
  private readonly url = 'http://localhost:8080/api/v1/actores';

  actores$: Observable<Actor[]> = this.http.get<Actor[]>(this.url);
}
```

# Integración en Plantilla HTML (`@for` y Pipe `async`)

```html
<label for="cboActor">Seleccionar Actor:</label>
<select id="cboActor" [(ngModel)]="idActorSeleccionado">
  <!-- El pipe async suscribe y cancela automáticamente el Observable -->
  @for (actor of actores$ | async; track actor.id) {
    <option [value]="actor.id">
      {{ actor.nombre }} {{ actor.apellidos }}
    </option>
  }
</select>
<button (click)="agregarActor()">Agregar Actor</button>
```

* **Data Binding:**
  * `[(ngModel)]`: Enlace bidireccional (*Two-Way Data Binding*).
  * `(click)`: Enlace de eventos (*Event Binding*).
  * `[value]`: Enlace de propiedades (*Property Binding*).
