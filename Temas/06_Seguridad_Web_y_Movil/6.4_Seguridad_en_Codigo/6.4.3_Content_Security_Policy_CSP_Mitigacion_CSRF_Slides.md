# Content Security Policy (CSP Nivel 3)

* Cabecera HTTP que indica al navegador qué recursos puede ejecutar.
* **Directivas Fundamentales:**
  * `default-src 'self'`: Solo orígenes del mismo dominio por defecto.
  * `script-src 'self' 'nonce-...'`: Bloquea scripts no autorizados o inline.
  * `connect-src 'self' https://api...`: Limita llamadas Ajax/Fetch.
  * `frame-ancestors 'none'`: Erradica ataques de *Clickjacking*.
* Bloquea la ejecución de scripts inyectados aunque exista una falla XSS.

---

# Mecánica del Ataque CSRF

* Ocurre cuando un sitio malicioso induce al navegador a enviar una petición no deseada.
* **Dependencia Crítica del Ataque:**
  * Depende de que el navegador **envíe automáticamente cookies de sesión** a sitios de destino.
* Si el usuario tiene una sesión abierta en su banco y visita un sitio malicioso, un formulario oculto puede transferir fondos a espaldas del usuario.

---

# ¿Por qué las APIs Móviles y Stateless no sufren CSRF?

* Las aplicaciones móviles (Flutter) y SPAs modernas utilizan la cabecera:
  `Authorization: Bearer <token_jwt>`
* Los navegadores **NUNCA** adjuntan cabeceras personalizadas automáticamente desde un sitio web externo.
* Un sitio malicioso no puede acceder a las variables locales de Flutter ni leer el token de otra pestaña.
* **En Spring Security:** Es seguro y estándar deshabilitar CSRF (`csrf.disable()`) cuando se usan tokens Bearer sin sesiones de cookies.

---

# Blindaje de Cookies con `SameSite=Strict`

* Si una aplicación web utiliza cookies de sesión, configure:
  * `Secure`: Solo viaja sobre conexiones HTTPS cifradas.
  * `HttpOnly`: Inaccesible desde scripts JavaScript (mitiga XSS).
  * `SameSite=Strict`: El navegador **bloquea el envío de la cookie** si la petición se originó en otro dominio.
* Neutraliza el vector de ataque CSRF de raíz a nivel de navegador.

---

# Configuración en Spring Boot 3 (Java 25)

```java
@Bean
public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
    return http
        .csrf(csrf -> csrf.disable()) // Stateless con JWT
        .headers(headers -> headers
            .contentSecurityPolicy(csp -> csp
                .policyDirectives("default-src 'self'; frame-ancestors 'none';")
            )
        )
        .build();
}
```

* Arquitectura limpia y resistente conforme a los estándares de la industria.
