# Niveles de Protección en Reposo

* **1. Cifrado a Nivel de Disco / TDE:**
  * Administrado por el motor de BD (PostgreSQL, SQL Server).
  * Protege contra el robo físico de los discos duros o cintas de backup.
  * Inconveniente: Si un usuario hace `SELECT`, los datos se ven en claro.
* **2. Cifrado a Nivel de Aplicación:**
  * Spring Boot cifra el campo antes de enviarlo a la base de datos.
  * Protege incluso si un atacante accede como administrador de la BD (DBA).
* **3. Cifrado Móvil con SQLCipher:**
  * Cifra página por página los archivos SQLite en dispositivos móviles.

# ¿Por qué AES-256-GCM?

* **Galois/Counter Mode (GCM):**
  * Estándar recomendado internacionalmente por NIST.
  * Combina **Confidencialidad** con **Integridad (AEAD)**.
* **Authentication Tag (128 bits):**
  * Si un atacante modifica un bit del registro cifrado, el descifrado falla.
* **Vector de Inicialización (IV):**
  * Debe ser de 12 bytes y **estrictamente aleatorio por cada fila**.
  * Reutilizar un IV destruye la seguridad matemática del algoritmo.

# Implementación de JPA Converter (Java 25)

```java
@Converter
public class CifradoAesConverter implements AttributeConverter<String, String> {

    @Override
    public String convertToDatabaseColumn(String datoClaro) {
        byte[] iv = new byte[12];
        secureRandom.nextBytes(iv); // IV aleatorio único

        Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
        cipher.init(Cipher.ENCRYPT_MODE, secretKey, 
                    new GCMParameterSpec(128, iv));
        
        byte[] cifrado = cipher.doFinal(datoClaro.getBytes(UTF_8));
        return empaquetarBase64(iv, cifrado);
    }
}
```

* Empaqueta el IV junto con el texto cifrado para su posterior lectura.

# Uso Declarativo en Entidades

```java
@Entity
@Table(name = "pacientes")
public class Paciente {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Convert(converter = CifradoAesConverter.class)
    @Column(name = "cedula_cifrada", nullable = false)
    private String cedula;
}
```

* Cifrado y descifrado transparente para la capa de servicios y controladores.

# SQLCipher en Móviles (Flutter 3)

* Sustituto directo de SQLite que cifra completamente la base de datos.
* Clave derivada mediante **PBKDF2 con 256.000 iteraciones**.
* La contraseña de la base de datos se guarda en `flutter_secure_storage`.
* Si el teléfono es conectado por USB en modo depuración (ADB), el archivo `.db` solo contendrá bytes ilegibles.
