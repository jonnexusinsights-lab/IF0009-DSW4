Introducción a Apache Maven

Gestión de Dependencias y Automatización del Ciclo de Vida de Software

Curso: IF0009 - Desarrollo de Software IV Docente: Mag. Jonathan Granados C. Universidad de Costa Rica

¿Qué es Apache Maven?

  • Herramienta estándar de la industria para la gestión de proyectos Java.
  • Basada en el concepto de POM (Project Object Model).
  • Filosofía central: Convención sobre Configuración.
    • Prescribe una estructura estándar de carpetas.
    • Evita la necesidad de codificar guiones manuales de compilación.
  • Automatiza la descarga de dependencias externas desde repositorios públicos.

Estructura Estándar de Maven

mi-proyecto/
├── pom.xml               <-- Configuración declarativa central
└── src/
    ├── main/
    │   ├── java/         <-- Código fuente del sistema (.java)
    │   └── resources/    <-- Configuraciones y assets
    └── test/
        └── java/         <-- Código de pruebas unitarias (JUnit)

Anatomía del Archivo pom.xml

  • Contiene toda la declaración técnica del proyecto en formato XML.
  • Define las coordenadas del proyecto (GAV):
    • groupId: Organización o paquete raíz.
    • artifactId: Nombre único del entregable.
    • version: Versión actual de compilación.
  • Declara la sección de que se bajarán automáticamente.

Ejemplo de un pom.xml Mínimo

<project xmlns="http://maven.apache.org/POM/4.0.0">
    <modelVersion>4.0.0</modelVersion>
    <groupId>cr.ac.ucr.if0009</groupId>
    <artifactId>proyecto-maven-demo</artifactId>
    <version>1.0.0-SNAPSHOT</version>

    <dependencies>
        <dependency>
            <groupId>com.google.code.gson</groupId>
            <artifactId>gson</artifactId>
            <version>2.10.1</version>
        </dependency>
    </dependencies>
</project>

Ciclos de Vida y Fases en Maven

Maven divide la compilación en fases lógicas ordenadas. Al ejecutar una fase, todas las anteriores se ejecutan automáticamente.
  • clean: Elimina el directorio de salidas anteriores (target/).
  • compile: Compila el código fuente a archivos .class.
  • test: Ejecuta las pruebas unitarias y genera reportes.
  • package: Empaqueta el código en formato ejecutable (.jar o .war).
  • install: Copia el entregable en el repositorio local de su máquina (.m2).

Maven en Visual Studio Code (VS Code)

Setup y Uso Diario

  1. Instalar Extensiones: Busque e instale el Extension Pack for Java y Maven for Java en el Marketplace.
  2. Importación Automática: Abra la carpeta del proyecto. VS Code analizará el pom.xml y configurará el entorno.
  3. Panel Interactivo de Maven: Use la vista lateral izquierda para ejecutar fases (compile, test, package) con un clic.
  4. Manejo de Dependencias: Modifique el XML directamente; la extensión se encargará de resolver el Classpath de inmediato.

Maven en Google Antigravity (AI IDE)

Desarrollo Asistido de Próxima Generación

  • Gestión Inteligente de Dependencias:
    • Pídale a la IA: "Agregue Gson al pom.xml" o "Actualice la versión de JUnit".
    • La IA insertará las etiquetas correctas de forma limpia.
  • Compilación y Depuración Automática:
    • Google Antigravity ejecuta fases de Maven en segundo plano.
    • Si compila con errores, la IA lee la salida de Maven y repara el código de inmediato.
  • Generación de Pruebas Automatizadas:
    • Solicite la creación de pruebas unitarias; el agente creará el archivo en src/test/java y ejecutará mvn test.
