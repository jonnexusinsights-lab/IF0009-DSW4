## Evolución del Estándar CSS

* CSS ha madurado incorporando nativamente herramientas que antes requerían preprocesadores (Sass/Less).
* Los navegadores modernos renderizan estas reglas en tiempo real de forma eficiente.
* Aumenta la mantenibilidad, escalabilidad y legibilidad de las hojas de estilo del proyecto.
* Permite crear interfaces que responden de manera adaptativa a nivel de <span class="highlight">componente individual</span>.

---

## 1. CSS Custom Properties (Variables)

* Permiten almacenar valores dinámicos y reutilizables en cascada.
* Declaración: prefijo `--` (comúnmente dentro del selector raíz `:root`).
* Consumo: mediante la función `var(--nombre-variable)`.
* <span class="highlight">Dinámicas en tiempo de ejecución:</span> Pueden modificarse mediante JavaScript o sobrescribirse dinámicamente dentro de Media Queries.

```css
:root {
  --color-primario: #2563eb;
  --radio-borde: 8px;
}
.tarjeta {
  background-color: var(--color-primario);
  border-radius: var(--radio-borde);
}
```

---

## 2. Nesting Nativo (Anidamiento)

* Estructura las reglas CSS de forma jerárquica, reflejando el orden del HTML.
* Evita la redundancia de selectores largos y repetitivos.
* Utiliza el símbolo `&` para referenciar explícitamente al selector del nodo padre.

```css
.tarjeta {
  padding: 20px;
  background-color: white;

  h3 {
    color: #333;
    font-size: 1.2rem;
  }
  &:hover {
    box-shadow: 0 4px 10px rgba(0,0,0,0.15);
  }
}
```

---

## 3. Container Queries

* **Media Queries:** Evalúan las dimensiones de la pantalla global del navegador (*viewport*).
* **Container Queries (`@container`):** Evalúan las dimensiones del <span class="highlight">contenedor inmediato</span> del elemento.
* Permite que el diseño del componente responda a la anchura del espacio asignado en la UI (ej. barra lateral vs. contenedor central).

```css
.contenedor-tarjeta {
  container-type: inline-size; /* Define al host contenedor */
}
@container (min-width: 500px) {
  .tarjeta-info {
    display: flex; /* Se adapta a horizontal si hay espacio */
  }
}
```

---

## 4. CSS Grid Moderno y Elástico

* Permite la creación de cuadrículas responsivas adaptables sin necesidad de declarar Media Queries fijas.
* Combina las funciones de ordenación elástica `repeat()`, `auto-fit` y `minmax()`.

```css
.cuadricula {
  display: grid;
  /* Repite columnas dinámicas de mínimo 280px y máximo 1 fracción equitativa */
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 20px;
}
```

## Trampas Comunes (Gotchas)

* <span class="highlight">Sensibilidad a mayúsculas/minúsculas:</span> Las variables CSS son estrictamente case-sensitive (`--Color-Fondo` != `--color-fondo`).
* <span class="highlight">Omitir el tipo de contenedor:</span> Las Container Queries fallarán silenciosamente si el elemento padre no tiene configurada explícitamente la propiedad `container-type: inline-size`.
* <span class="highlight">Soporte en navegadores antiguos:</span> Las Container Queries son modernas; si bien el soporte actual es excelente en navegadores modernos, requiere polyfills en proyectos dirigidos a plataformas legadas.
