Git vs GitHub: Diferencias Fundamentales

  • Git (Local):
    • Motor de control de versiones distribuido.
    • Funciona localmente en su máquina, sin conexión a Internet.
    • Registra el historial de cambios mediante instantáneas (snapshots).
  • GitHub (Remoto):
    • Plataforma en la nube para alojar repositorios Git.
    • Permite la colaboración mediante herramientas de revisión y gestión.
    • Soporta Pull Requests, Issues y CI/CD.

Flujo de Trabajo Básico en Git

[ Directorio Local ] --( git add )--> [ Área Staging ]
                                            |
                                      ( git commit )
                                            v
[ GitHub (Remoto) ]  <--( git push )-- [ Repositorio Local ]
  • git add: Prepara archivos modificados.
  • git commit: Consolida los cambios en el historial local.
  • git push: Sube el historial de commits al servidor central.

Gestión de Ramas (Feature Branching)

  • La rama main es sagrada: Siempre debe compilar y contener código estable de producción.
  • Ramas de características (feature/):
    • Se crean de manera temporal para trabajar de forma aislada.
    • Evita interferencias en el trabajo de sus compañeros de equipo.
  • Comando:
git checkout -b feature/mi-nueva-caracteristica

Pull Requests y Conflictos de Mezcla

  • Pull Request (PR):
    • Propuesta formal para fusionar una rama temporal en main.
    • Facilita la revisión de código por pares y la retroalimentación.
  • Conflictos de Mezcla (Merge Conflicts):
    • Ocurren cuando dos ramas editan las mismas líneas de un archivo.
    • Git detiene la fusión y requiere resolución humana manual.
    • ¡No es un error del sistema, es parte del flujo normal!

Git y GitHub en Visual Studio Code

Operaciones sin Consola

  • Pestaña Source Control: Muestra los archivos modificados con un diff visual intuitivo.
  • Gestión de Cambios Interactiva:
    • Haga clic en + para preparar (stage) cambios.
    • Escriba el mensaje del commit y confirme de forma gráfica.
  • Editor de Conflictos Visual:
    • VS Code resalta el conflicto y provee botones rápidos para aceptar cambios locales, entrantes o ambos.

Control de Versiones con Google Antigravity

Asistencia Inteligente de Desarrollo

  • Commits Semánticos Automáticos:
    • La IA lee su git diff y genera mensajes detallados siguiendo estándares profesionales.
  • Resolución Asistida de Conflictos:
    • Delegue el análisis a Google Antigravity.
    • La IA evalúa la coherencia lógica de ambas versiones y resuelve el conflicto sin romper la compilación de Maven.
  • Sanitización de Repositorios:
    • La IA le ayuda a configurar archivos .gitignore para no subir claves ni carpetas innecesarias (como target/).
