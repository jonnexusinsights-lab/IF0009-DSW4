¿Qué son los Web Components?

  • Estándar nativo del consorcio W3C para la web moderna.
  • Permiten crear etiquetas HTML personalizadas y reutilizables.
  • Funcionan directamente en el navegador sin dependencias externas ni frameworks (como Angular o React).
  • Promueven el desacoplamiento y el encapsulamiento limpio.
  • Los nombres de etiquetas personalizadas deben contener un guion medio (-) por estándar.

Los Tres Pilares del Estándar

  1. Custom Elements:
APIs de JavaScript para definir nuevos elementos HTML con lógica de control asociada a clases heredadas de HTMLElement.
  1. Shadow DOM (DOM en la Sombra):
Aísla y encapsula el HTML y CSS del componente, evitando que los estilos de la página principal se filtren o afecten al componente.
  1. HTML Templates (<template> y <slot>):
Estructuras de marcado declaradas en HTML que no se renderizan al cargar la página, listas para ser clonadas e inyectadas dinámicamente.

Shadow DOM: Concepto Visual

[ DOM Principal de la Página (Light DOM) ]
                   │
                   └── <tarjeta-contacto> (Shadow Host)
                                │
                                └── #shadow-root (Barrera de Aislamiento)
                                             ├── <style> (CSS aislado)
                                             ├── <div> (Estructura interna)
                                             └── <slot> (Punto de inyección)

Plantillas y Slots (<template> / <slot>)

  • La etiqueta <template> define la estructura base y los estilos privados.
  • El elemento <slot> actúa como un marcador de posición para inyectar contenido externo. 
<template id="mi-plantilla">
    <style>
        .caja { padding: 10px; border: 1px solid #ccc; }
    </style>
    <div class="caja">
        <!-- Contenido dinámico del exterior caerá aquí -->
        <slot name="mensaje">Mensaje predeterminado</slot>
    </div>
</template>

Estructura de Código del Componente (JS)

class TarjetaContacto extends HTMLElement {
    constructor() {
        super();
        // 1. Activar Shadow DOM
        this.attachShadow({ mode: 'open' });

        // 2. Clonar la plantilla e inyectarla
        const plantilla = document.getElementById('plantilla-tarjeta');
        const clon = plantilla.content.cloneNode(true);
        this.shadowRoot.appendChild(clon);
    }
}
// Registrar la etiqueta en el navegador
customElements.define('tarjeta-contacto', TarjetaContacto);

Atributos de Datos Personalizados (data-*)

  • Mecanismo estándar de HTML5 para embeber datos en elementos HTML.
  • Sintaxis: data-nombre-atributo="valor".
  • Accesibles dinámicamente desde JavaScript mediante el mapa dataset de la API del DOM. 
<!-- Declaración en HTML -->
<tarjeta-contacto data-rol="Administrador" data-user-id="101">
</tarjeta-contacto>

<script>
    // Lectura en JS
    const rol = elemento.dataset.rol; // "Administrador"
    const userId = elemento.dataset.userId; // "101" (camelCase automático)
</script>

Trampas Comunes (Gotchas)

  • Etiquetas autocerrables: Los Custom Elements no admiten la sintaxis <mi-elemento />. Deben cerrarse formalmente: <mi-elemento></mi-elemento>.
  • Estilos globales: El Shadow DOM bloquea estilos externos. Si usa Bootstrap o Tailwind globales, no afectarán los elementos internos de su Web Component de manera automática.
  • Indexación SEO: Buscadores antiguos y lectores de pantalla pueden tener problemas si la información clave del negocio reside puramente en variables del Shadow DOM.
