# ¿Qué es un Procedimiento Almacenado?

* **Definición:** Bloque de código SQL compilado y guardado directamente en el servidor de base de datos (SQL Server, PostgreSQL, Oracle).
* **Ventajas Empresariales:**
  * **Rendimiento:** Plan de ejecución precompilado y optimizado por el motor.
  * **Seguridad:** Abstracción de tablas y prevención de inyecciones SQL.
  * **Centralización:** Lógica de datos pesada ejecutada cerca de los datos.
* **Integración con Hibernate:** Hibernate actúa como puente para ejecutar el procedimiento y convertir sus resultados a objetos Java.

# Modos de Integración en el Stack Java

1. **Anotación `@Procedure` (Spring Data JPA):**
   * El enfoque más limpio y declarativo.
   * Mapea un método de interfaz `@Repository` directamente a la firma SQL.
2. **Anotación `@NamedStoredProcedureQuery` (JPA Standard):**
   * Definida sobre la clase de Entidad (`@Entity`).
   * Especifica el nombre, parámetros (`IN`, `OUT`, `REF_CURSOR`) y `ResultSets`.
3. **API `StoredProcedureQuery` (API `EntityManager`):**
   * Control dinámico de bajo nivel para invocaciones complejas en tiempo de ejecución.

# Tipos de Parámetros (`ParameterMode`)

* **`ParameterMode.IN`:** Parámetro de entrada hacia el procedimiento.
* **`ParameterMode.OUT`:** Valor de retorno calculado por el procedimiento.
* **`ParameterMode.INOUT`:** Parámetro bidireccional (envía y recibe datos).
* **`ParameterMode.REF_CURSOR`:** Cursor para iterar múltiples filas en Oracle / PostgreSQL.

```java
@StoredProcedureParameter(mode = ParameterMode.IN, name = "p_dpto", type = String.class)
@StoredProcedureParameter(mode = ParameterMode.OUT, name = "p_total", type = Integer.class)
```

# Ejemplo SQL: Stored Procedure en SQL Server

```sql
CREATE PROCEDURE sp_calcular_metricas_salario
    @p_departamento VARCHAR(50),
    @p_total_empleados INT OUTPUT,
    @p_promedio_salario DECIMAL(12,2) OUTPUT
AS
BEGIN
    SET NOCOUNT ON;
    
    SELECT 
        @p_total_empleados = COUNT(*),
        @p_promedio_salario = ISNULL(AVG(salario), 0.00)
    FROM Empleado
    WHERE departamento = @p_departamento AND activo = 1;
END;
GO
```

# Mapeo en la Entidad con `@NamedStoredProcedureQuery`

```java
@Entity
@Table(name = "Empleado")
@NamedStoredProcedureQuery(
    name = "Empleado.spCalcularMetricasSalario",
    procedureName = "sp_calcular_metricas_salario",
    parameters = {
        @StoredProcedureParameter(mode = ParameterMode.IN, name = "p_departamento", type = String.class),
        @StoredProcedureParameter(mode = ParameterMode.OUT, name = "p_total_empleados", type = Integer.class),
        @StoredProcedureParameter(mode = ParameterMode.OUT, name = "p_promedio_salario", type = BigDecimal.class)
    }
)
public class Empleado { ... }
```

# Repositorio Declarativo con `@Procedure`

```java
@Repository
public interface EmpleadoRepository extends JpaRepository<Empleado, Long> {

    // Invocación directa del procedimiento por nombre nativo
    @Procedure(procedureName = "sp_obtener_empleados_por_departamento")
    List<Empleado> obtenerEmpleadosPorDepartamento(@Param("p_departamento") String dpto);

    // Invocación del NamedStoredProcedureQuery de la entidad
    @Procedure(name = "Empleado.spCalcularMetricasSalario")
    Map<String, Object> spCalcularMetricasSalario(@Param("p_departamento") String dpto);
}
```

# Invocación Dinámica con `EntityManager`

```java
@Service
public class EmpleadoService {

    @PersistenceContext
    private EntityManager entityManager;

    @Transactional(readOnly = true)
    public Map<String, Object> ejecutarSPMetricas(String dpto) {
        StoredProcedureQuery query = entityManager.createStoredProcedureQuery("sp_calcular_metricas_salario");
        query.registerStoredProcedureParameter("p_departamento", String.class, ParameterMode.IN);
        query.registerStoredProcedureParameter("p_total_empleados", Integer.class, ParameterMode.OUT);
        query.registerStoredProcedureParameter("p_promedio_salario", BigDecimal.class, ParameterMode.OUT);

        query.setParameter("p_departamento", dpto);
        query.execute();

        Integer total = (Integer) query.getOutputParameterValue("p_total_empleados");
        BigDecimal promedio = (BigDecimal) query.getOutputParameterValue("p_promedio_salario");
        return Map.of("total", total, "promedio", promedio);
    }
}
```

# Trampas Comunes y Buenas Prácticas

* **Falta de `@Transactional`:**
  * Causa `TransactionRequiredException` o desconexión de cursores.
* **Incompatibilidad de Dialectos:**
  * SQL Server usa `SELECT` directos; Oracle/PostgreSQL requieren `REF_CURSOR`.
* **Pérdida de Portabilidad:**
  * Migrar de motor de BD obliga a reescribir procedimientos SQL nativos.
