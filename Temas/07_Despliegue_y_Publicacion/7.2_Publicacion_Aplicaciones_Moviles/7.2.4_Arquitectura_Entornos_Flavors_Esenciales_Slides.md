* Estructurar puntos de entrada independientes en Dart.

---

# ¿Por qué usar Flavors?

* **El Antipatrón Peligroso:**
  * Modificar `baseUrl = "http://localhost"` a mano antes de publicar.
  * Tarde o temprano una versión de prueba llegará a producción por error humano.
* **La Solución con Flavors:**
  * Compilación segregada y reproducible.
  * Ambas versiones coexisten en el mismo dispositivo físico sin conflicto.

---

# Configuración en Gradle (`build.gradle`)

```groovy
android {
    flavorDimensions "default"
    productFlavors {
        dev {
            dimension "default"
            applicationIdSuffix ".dev"
            resValue "string", "app_name", "UCR (DEV)"
        }
        prod {
            dimension "default"
            resValue "string", "app_name", "UCR Oficial"
        }
    }
}
```

* `applicationIdSuffix ".dev"` crea un identificador de paquete independiente en Android.

---

# Puntos de Entrada en Dart

```dart
// lib/main_dev.dart
void main() {
  AppConfig.instancia = AppConfig(
    nombre: 'UCR (DEV)',
    apiUrl: 'http://10.0.2.2:8080/api/v1',
  );
  iniciarApp();
}

// lib/main_prod.dart
void main() {
  AppConfig.instancia = AppConfig(
    nombre: 'UCR',
    apiUrl: 'https://api.ucr.ac.cr/api/v1',
  );
  iniciarApp();
}
```

---

# Comandos de Ejecución y Compilación

* **Ejecutar en Desarrollo:**
  ```bash
  flutter run --flavor dev -t lib/main_dev.dart
  ```
* **Compilar para Producción:**
  ```bash
  flutter build appbundle --flavor prod -t lib/main_prod.dart
  ```
* Automatiza la segregación de variables sin riesgo de error.
