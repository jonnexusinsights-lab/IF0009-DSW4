Registros DNS Esenciales

  • A (Address): Apunta un nombre de dominio directamente a una IP IPv4:
api.ucr.ac.cr $\longrightarrow$ 198.51.100.25
  • AAAA: Apunta el dominio a una dirección IPv6.
  • CNAME (Alias Canónico): Apunta un subdominio a otro dominio:
portal.ucr.ac.cr $\longrightarrow$ ucr.ac.cr
  • TXT: Almacena registros alfanuméricos de verificación y seguridad (SPF/DKIM).
  • TTL (Time To Live): Tiempo de vida en caché de los servidores intermedios.

Let's Encrypt y el Protocolo ACME (RFC 8555)

  • Autoridad Certificadora Libre y Automatizada:
    • Emite certificados válidos por 90 días.
  • Desafío HTTP-01:
    • Let's Encrypt solicita colocar un token en /.well-known/acme-challenge/.
    • La CA verifica la ruta vía HTTP; si coincide, emite el certificado X.509.
  • Desafío DNS-01:
    • Inserción de un registro TXT en el DNS (usado para certificados Wildcard *.dominio.com).

Emisión con Certbot en Linux

# Emisión en modo standalone
sudo certbot certonly --standalone \
  -d api.mi-dominio.com \
  --agree-tos \
  -m admin@mi-dominio.com
  • Genera fullchain.pem (clave pública + cadena intermedia) y privkey.pem (clave privada).
  • Renovación Automatizada: certbot renew --quiet ejecutado por un timer de systemd.

Configuración de HTTPS en Spring Boot 3

server.port=443
server.ssl.key-store=file:/var/certs/keystore-prod.p12
server.ssl.key-store-type=PKCS12
server.ssl.key-store-password=ClaveSuperSegura2026!
server.ssl.enabled-protocols=TLSv1.3
  • Cifra el tráfico de la API con el protocolo más moderno y seguro (TLS 1.3).
