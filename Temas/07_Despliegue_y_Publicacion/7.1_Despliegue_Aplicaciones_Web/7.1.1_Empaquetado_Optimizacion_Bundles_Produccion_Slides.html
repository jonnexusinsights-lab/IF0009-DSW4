Tema 7.1.1: Empaquetado y Optimización

Bundling en Angular 17+, Fat JARs en Spring Boot 3 y Calibración JVM

Curso: IF0009 - Desarrollo de Software IV Profesor: Mag. Jonathan Granados C. Semestre: II-2026 | Universidad de Costa Rica

Objetivos de la Sesión

  • Dominar la compilación AOT (Ahead-Of-Time) y Tree Shaking en Angular.
  • Comprender la técnica de Cache Busting con hashes de contenido.
  • Empaquetar aplicaciones en Fat JARs ejecutables con Maven.
  • Configurar perfiles de producción (prod) en Spring Boot 3.
  • Calibrar parámetros de memoria y Garbage Collection en Java 25.

Optimización Frontend: Angular 17+

  • Compilación AOT: Transforma plantillas a código JS altamente optimizado.
  • Tree Shaking: Descarta código muerto y funciones nunca invocadas.
  • Lazy Loading & Code Splitting:
    • Divide la aplicación en bloques (chunks) pequeños.
    • Solo descarga los componentes de la ruta activa del usuario.
  • Cache Busting (main.[hash].js):
    • Obliga al navegador a renovar la caché únicamente cuando el código cambia.

Compilación de Producción en Angular

# Genera bundles optimizados en dist/mi-app/
ng build --configuration production
  • Directivas automáticas en angular.json:
    • optimization: true (minificación con esbuild/Terser).
    • outputHashing: "all" (hashes en JS, CSS y activos).
    • sourceMap: false (protege el código TypeScript original).

Optimización Backend: Spring Boot 3 (Java 25)

  • Fat JAR Autónomo: Empaqueta código, librerías y Tomcat embebido:
```bash mvn clean package -DskipTests ```
  • Perfil prod (application-prod.yml):
    • Deshabilita consolas de prueba e impresiones de trazas de excepción.
    • Establece validación estricta de esquema: hibernate.ddl-auto=validate.
    • Optimiza el pool de conexiones relacional (HikariCP).

Calibración de la JVM en Servidores

java -server \
  -Xms512m -Xmx2048m \
  -XX:+UseG1GC \
  -Dspring.profiles.active=prod \
  -jar aplicacion.jar
  • -Xms / -Xmx: Evita que la JVM compita por memoria con otros procesos.
  • -XX:+UseG1GC: Recolector de basura optimizado para alta concurrencia.
