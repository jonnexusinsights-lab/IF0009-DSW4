# Arquitectura Desacoplada Moderna

* **Hosting Estático (Frontend Angular):**
  * Despacha archivos inmutables precompilados (`index.html`, `main.[hash].js`).
  * Puede alojarse en CDNs o servidores web con latencia ultrabaja.
* **Hosting Dinámico (Backend Spring Boot):**
  * Procesa peticiones RESTful, seguridad JWT y persistencia en base de datos.
  * Ejecuta la máquina virtual Java con Tomcat embebido.

---

# El Dilema del Error 404 en SPAs

* **Enrutamiento del Lado del Cliente (Client-Side):**
  * Angular utiliza la History API (`pushState`) para cambiar URLs en memoria.
  * El servidor físico **no tiene carpetas** para `/perfil` o `/reportes`.
* **El Problema del F5:**
  * Si el usuario recarga la página, el navegador pide `GET /perfil`.
  * El servidor estático responde con **404 Not Found**.
* **Solución Obligatoria:**
  * Reescritura de URLs para redirigir toda ruta no física a `index.html`.

---

# Reglas de Caché HTTP Defensivas

* **`index.html`:**
  * `Cache-Control: no-cache, no-store, must-revalidate`
  * El navegador siempre consulta si hay un nuevo archivo inicial.
* **Activos con Hash (`main.8a2f.js`):**
  * `Cache-Control: public, max-age=31536000, immutable`
  * Inalterable en el tiempo; se almacena en memoria caché 1 año.
* Garantiza que los usuarios vean cambios inmediatamente tras un despliegue.

---

# Servidor Dinámico en Spring Boot 3

```properties
# Tomcat Embebido Optimizado
server.port=8080
server.tomcat.threads.max=200
server.tomcat.threads.min-spare=20
server.tomcat.max-connections=8192

# Compresión Gzip de JSON
server.compression.enabled=true
server.compression.mime-types=application/json
server.compression.min-response-size=2048
```

* Rendimiento elevado y compresión automática de respuestas grandes.
