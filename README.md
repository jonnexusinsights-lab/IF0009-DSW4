# Planificación y Contenidos: IF0009 - Desarrollo de Software IV

Este repositorio contiene los materiales de planificación, lecturas conceptuales, laboratorios prácticos, evaluaciones y diapositivas interactivas para el curso **IF0009 - Desarrollo de Software IV (II Ciclo 2026)** de la carrera de Informática Empresarial en la Universidad de Costa Rica (UCR), Recinto de Paraíso.

---

## 📂 Estructura General del Repositorio

El proyecto se encuentra organizado en las siguientes carpetas y capas:

*   **`Temas/`**: Contiene las lecturas teóricas (`.md`) y presentaciones (`_Slides.md`, `_Slides.html`) ordenadas por módulos según el programa oficial:
    *   `01_Fundamentos_Desarrollo_Web/` (Temas 1.1 y 1.2 generados).
    *   `02_Tecnologias_Backend/`
    *   `03_Tecnologias_Frontend/`
    *   `04_Persistencia_Datos/`
    *   `05_Seguridad_Web/`
    *   `06_Desarrollo_Movil/`
    *   `07_Arquitectura_Software/`
*   **`Evaluaciones/`**: Espacio centralizado para las pruebas de conocimiento y retos prácticos del curso:
    *   `Examenes/`, `Laboratorios/`, `Quices/`, `Tareas/`, `Talleres/`, `Investigaciones/`, `Proyectos/`.
*   **`agentic_knowledge/`**: Recursos de configuración e instrucciones para el asistente virtual de codificación y la única fuente de verdad:
    *   `project_context.md`: Contexto unificado del curso (cronograma de 18 semanas, rubros de evaluación, seguimiento de entregables).
    *   `modes.md`, `roles.md`, `skills.md`: Prompt bundles del asistente.
*   **`src/python_utils_src/`**: Herramientas y scripts utilitarios del repositorio:
    *   `marp_to_reveal.py`: Compilador ligero autónomo de Markdown (sintaxis Marp) a presentaciones interactivas HTML basadas en Reveal.js y Highlight.js.
*   **`resources/`**: Programa institucional del curso en PDF y consolidados de planificación curricular.
